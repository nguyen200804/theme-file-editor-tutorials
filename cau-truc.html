Cấu trúc thư mục

Sắp xếp các thư mục và tập tin trong theme rõ ràng, phục vụ mở rộng và bảo trì lâu dài.

ten-theme/
├── style.css              # bắt buộc
├── index.php              # bắt buộc, dự phòng cuối
├── functions.php
├── header.php  footer.php  sidebar.php  comments.php
├── search.php  404.php
│
├── page/                  # trang tĩnh (post type page)
│   ├── front-page.php       # trang chủ
│   ├── home.php             # trang blog
│   ├── page.php             # mọi trang còn lại
│   └── page-lien-he.php     # riêng slug lien-he
├── single/                # chi tiết một bài
│   ├── single.php           # post và custom post type
│   ├── single-san-pham.php  # riêng post type san-pham
│   └── singular.php         # dự phòng chung post + page
├── archive/               # danh sách bài
│   ├── archive.php          # dự phòng mọi danh sách
│   ├── category.php  tag.php  author.php
│   ├── taxonomy-loai-san-pham.php
│   └── archive-san-pham.php
├── templates/             # Page Template chọn tay (Template Name:)
├── template-parts/        # phần dùng lại
│   ├── section/  loop/  content/  ui/  layout/  form/
├── inc/
│   ├── template-loader.php
│   ├── custom-post-types.php
│   ├── custom-taxonomies.php
│   └── fields/            # custom field thay ACF
└── assets/  css/ js/ images/ fonts/

Tên {key} trong single-{key}.php hoặc taxonomy-{key}.php là key trong register_post_type() / register_taxonomy(), không phải label hiển thị.
