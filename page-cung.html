Tạo Page cứng (Page Template)

Tài liệu hướng dẫn chi tiết từ cơ chế nạp template, các phương pháp tạo trang, khung code chuẩn (boilerplate) đến tích hợp Custom Fields và tự động nạp CSS/JS riêng theo từng trang.

I. Cơ chế hoạt động của WordPress khi tải một Page

Khi người dùng truy cập vào một trang tĩnh (URL dạng: domain.com/ten-trang/), nhờ bộ nạp template (như inc/template-loader.php hoặc quy chuẩn WordPress), hệ thống sẽ quét file theo thứ tự ưu tiên từ trên xuống dưới và dừng lại ngay khi tìm thấy file đầu tiên tồn tại:

1. Template được chọn tay trong Admin (templates/*.php)  [Ưu tiên cao nhất]
   ↓ (nếu trang để "Giao diện mặc định")
2. page/page-{slug}.php  (Tìm theo slug URL, ví dụ: page-gioi-thieu.php)
   ↓ (nếu không có)
3. page/page-{id}.php    (Tìm theo ID bài viết, ví dụ: page-42.php)
   ↓ (nếu không có)
4. page/page.php         (Template trang tĩnh dùng chung)
   ↓ (nếu không có)
5. singular.php          (Dự phòng chung cho bài viết và trang tĩnh)
   ↓ (nếu không có)
6. index.php             [Lưới an toàn cuối cùng của theme]
📌 Lưu ý cho Trang Chủ: Nếu trang được cấu hình làm Trang chủ tĩnh trong Cài đặt → Đọc (Settings → Reading), WordPress luôn ưu tiên nạp file page/front-page.php (hoặc front-page.php) trước tất cả các file trên.

So sánh cơ chế giữa Page Template và Slug Template

Tiêu chí Page Template (Chọn tay) Slug Template (Theo URL)
Cơ chế nhận diện Quét comment Template Name: ở đầu file và đọc trường meta _wp_page_template trong Database. Khớp trực tiếp tên file với chuỗi slug (đường dẫn URL) của trang.
Vị trí lưu file Thư mục con templates/ hoặc thư mục gốc theme. Thư mục page/ (nếu dùng loader) hoặc thư mục gốc theme.
Đổi đường dẫn URL Không ảnh hưởng: Đổi slug URL thì template vẫn giữ nguyên. Mất giao diện: Đổi slug URL là mất liên kết, tự rơi về page.php.
Khả năng tái sử dụng Một template có thể gán cho nhiều trang khác nhau (ví dụ: Landing Page A, B). Chỉ áp dụng cho duy nhất 1 trang có đúng slug đó.

II. 3 Phương pháp tạo Page phổ biến

Cách 1: Tạo tự động theo Slug URL (Khuyên dùng cho trang cố định)

Áp dụng cho các trang có đường dẫn cố định và đặc thù như: Giới thiệu, Liên hệ, Chính sách bảo mật...

  1. Vào Admin → Trang (Pages), xem Đường dẫn (Slug) của trang (Ví dụ: slug là lien-he).
  2. Mở thư mục page/ trong theme và tạo file: page/page-lien-he.php (hoặc page-lien-he.php ở thư mục gốc theme).
  3. Viết code cho file. WordPress sẽ tự động gọi file này mỗi khi truy cập domain.com/lien-he/ mà không cần thao tác gán giao diện trong Admin.

Cách 2: Tạo Custom Template chọn tay trong Admin

Áp dụng cho các giao diện cần tái sử dụng linh hoạt: Trang Landing Page sự kiện, Trang tràn viền (Fullwidth), Trang có thanh bên (Sidebar)...

  1. Vào thư mục templates/, tạo file mới (ví dụ: templates/template-landing.php).
  2. Khai báo dòng comment bắt buộc ở đầu file: 
    <?php
/**
 * Template Name: Giao Diện Landing Page Đặc Biệt
 * Template Post Type: page
 */
get_header(); ?>
  3. Vào Admin → Trang → Sửa trang. Tại cột bên phải mục Thuộc tính trang (Page Attributes) → Giao diện (Template), chọn "Giao Diện Landing Page Đặc Biệt" và nhấn Cập nhật.

Cách 3: Tạo Trang Chủ (Front Page)

  1. Tạo file page/front-page.php (hoặc front-page.php ở thư mục gốc theme).
  2. Vào Admin → Trang (Pages) → Thêm trang mới, tạo trang có tên là "Trang chủ" (slug: trang-chu).
  3. Vào Cài đặt → Đọc (Settings → Reading):
    • Tại mục Bố cục trang chủ (Your homepage displays): chọn Một trang tĩnh (A static page).
    • Mục Trang chủ (Homepage): chọn trang Trang chủ vừa tạo và bấm Lưu thay đổi.

III. Khung code mẫu chuẩn (Boilerplate) - Copy dán dùng ngay

Sườn code chuẩn mực đã tích hợp đầy đủ Header, Footer, The Loop, tiêu đề, nội dung và các vị trí ghép linh kiện:

<?php
/**
 * Template Name: [Tên hiển thị nếu là template chọn tay]
 * Description: Template trang tùy biến chuẩn WordPress
 */

// 1. Nạp Header
get_header(); ?>

<!-- 2. Thẻ bao bọc trang chính (có class động theo slug để viết CSS scoped) -->
<main id="primary" class="site-main page-custom page-<?php echo esc_attr( $post->post_name ?? 'custom' ); ?>">

    <?php
    // 3. Vòng lặp WordPress Loop chuẩn
    while ( have_posts() ) : the_post(); ?>

        <!-- Tiêu đề trang -->
        <header class="page-header container">
            <h1 class="page-title"><?php the_title(); ?></h1>
            <?php if ( has_excerpt() ) : ?>
                <div class="page-lead lead"><?php echo get_the_excerpt(); ?></div>
            <?php endif; ?>
        </header>

        <!-- Nội dung soạn thảo từ Admin (nếu có) -->
        <?php if ( get_the_content() ) : ?>
            <div class="entry-content container">
                <?php the_content(); ?>
            </div>
        <?php endif; ?>

        <!-- 4. Ghép các khối Section linh kiện (nếu chia nhỏ trong template-parts) -->
        <div class="page-sections">
            <?php
            // get_template_part( 'template-parts/section/intro' );
            // get_template_part( 'template-parts/section/services' );
            // get_template_part( 'template-parts/section/cta' );
            ?>
        </div>

    <?php endwhile; // Kết thúc Loop ?>

</main>

<!-- 5. Nạp Footer -->
<?php get_footer(); ?>

IV. Tích hợp nâng cao: Custom Fields & CSS/JS riêng

1. Lấy dữ liệu Custom Fields (thay thế ACF)

Khi dùng bộ Custom Fields tự viết thuần (xem thêm bài Custom Field thay ACF và bài Tra cứu 15 kiểu field), bạn lấy dữ liệu ngay trong template bằng các hàm gọn gàng:

// Lấy trường chữ (text, number, url...)
$hotline = ten_field( 'hotline' );
if ( $hotline ) {
    echo '<p class="hotline">Hotline: <strong>' . esc_html( $hotline ) . '</strong></p>';
}

// In ảnh đại diện kích thước lớn ('full', 'large', hoặc custom size)
echo ten_image( 'anh_banner', 'full' );

// Lấy danh sách repeater hoặc dữ liệu mảng
$features = ten_field( 'danh_sach_tinh_nang' );
if ( ! empty( $features ) && is_array( $features ) ) {
    echo '<ul class="feature-list">';
    foreach ( $features as $item ) {
        echo '<li>' . esc_html( $item['title'] ?? '' ) . '</li>';
    }
    echo '</ul>';
}

2. Tự động nạp CSS & JS riêng cho trang (Auto-Enqueue)

Để tối ưu tốc độ tải trang (PageSpeed), không nên nhồi toàn bộ CSS/JS vào một file khổng lồ. Theme có thể kích hoạt cơ chế tự quét và nạp file tương ứng trong thư mục assets/:

Trang đang xem File CSS tự nạp File JS tự nạp
Trang chủ assets/css/front-page.css assets/js/front-page.js
Trang Liên hệ (slug: lien-he) assets/css/page-lien-he.css assets/js/page-lien-he.js
Template Landing (tên file: template-landing.php) assets/css/template-landing.css assets/js/template-landing.js
Tất cả các Page khác (dự phòng chung) assets/css/page.css assets/js/page.js

Đoạn mã xử lý tự động nạp assets đặt trong functions.php:

function theme_page_assets() {
    if ( ! is_page() && ! is_front_page() ) {
        return;
    }

    $theme_dir = get_template_directory();
    $theme_uri = get_template_directory_uri();

    // 1. Xác định tên định danh theo trang: front-page hoặc page-{slug}
    if ( is_front_page() ) {
        $asset_name = 'front-page';
    } else {
        global $post;
        $asset_name = 'page-' . ( $post->post_name ?? '' );
    }

    // 2. Tự nạp CSS nếu file tồn tại
    if ( file_exists( $theme_dir . "/assets/css/{$asset_name}.css" ) ) {
        wp_enqueue_style( "theme-{$asset_name}", $theme_uri . "/assets/css/{$asset_name}.css", array(), filemtime( $theme_dir . "/assets/css/{$asset_name}.css" ) );
    } elseif ( file_exists( $theme_dir . '/assets/css/page.css' ) ) {
        wp_enqueue_style( 'theme-page-default', $theme_uri . '/assets/css/page.css', array(), filemtime( $theme_dir . '/assets/css/page.css' ) );
    }

    // 3. Tự nạp JS nếu file tồn tại
    if ( file_exists( $theme_dir . "/assets/js/{$asset_name}.js" ) ) {
        wp_enqueue_script( "theme-{$asset_name}", $theme_uri . "/assets/js/{$asset_name}.js", array( 'jquery' ), filemtime( $theme_dir . "/assets/js/{$asset_name}.js" ), true );
    } elseif ( file_exists( $theme_dir . '/assets/js/page.js' ) ) {
        wp_enqueue_script( 'theme-page-default', $theme_uri . '/assets/js/page.js', array( 'jquery' ), filemtime( $theme_dir . '/assets/js/page.js' ), true );
    }
}
add_action( 'wp_enqueue_scripts', 'theme_page_assets' );

V. Những lưu ý quan trọng và cách khắc phục lỗi

⚠️ Quên vòng lặp The Loop:
Nếu không có while ( have_posts() ) : the_post();, các hàm như the_title(), the_content(), the_post_thumbnail() hoặc ten_field() sẽ không lấy được đúng dữ liệu của trang hiện tại. Ngoài ra, các plugin SEO (Rank Math, Yoast SEO) và shortcode sẽ bị sai lệch ngữ cảnh.
👉 Xem bài phân tích chi tiết: Khi nào nên dùng while ( have_posts() ) : the_post();
⚠️ Vòng lặp phụ (Custom Query) đè dữ liệu trang chính:
Khi trong Page cứng có truy vấn thêm dữ liệu khác (như lấy tin tức, đối tác, sản phẩm bằng new WP_Query()), bạn bắt buộc phải gọi wp_reset_postdata(); ngay sau khi kết thúc loop phụ. Nếu quên, toàn bộ mã phía dưới và Footer sẽ nhận nhầm ID của bài viết cuối cùng trong loop phụ!
⚠️ Gặp lỗi 404 sau khi tạo trang:
Vào ngay Cài đặt → Đường dẫn tĩnh (Settings → Permalinks) và bấm nút Lưu thay đổi (Save Changes) một lần để WordPress làm mới lại bộ nhớ đệm (Flush Rewrite Rules).

VI. Ví dụ ứng dụng thực tế

1. Trang chủ (page/front-page.php)

<?php
/**
 * Template Name: Trang chủ
 */
get_header(); ?>

<main id="primary" class="site-main front-page">
    <?php
    // Ghép các section tái sử dụng từ template-parts/section/
    get_template_part( 'template-parts/section/hero' );
    get_template_part( 'template-parts/section/intro' );
    get_template_part( 'template-parts/section/services' );
    get_template_part( 'template-parts/section/stats' );
    get_template_part( 'template-parts/section/cta' );
    get_template_part( 'template-parts/section/latest-news' );
    ?>
</main>

<?php get_footer(); ?>

2. Trang Đội ngũ (templates/page-team.php)

<?php
/**
 * Template Name: Trang Đội ngũ
 * Template Post Type: page
 */
get_header(); ?>

<main id="primary" class="site-main page-team container">
    <header class="team-header text-center">
        <h1><?php the_title(); ?></h1>
        <p class="lead">Đội ngũ nhân sự chuyên môn cao của công ty.</p>
    </header>

    <div class="team-grid">
        <?php
        $team_query = new WP_Query( array(
            'post_type'      => 'thanh-vien',
            'posts_per_page' => -1,
            'orderby'        => 'menu_order',
            'order'          => 'ASC',
        ) );

        if ( $team_query->have_posts() ) :
            while ( $team_query->have_posts() ) : $team_query->the_post();
                get_template_part( 'template-parts/loop/card', 'thanh-vien' );
            endwhile;
            // Bắt buộc reset postdata để bảo toàn biến $post của Page chính!
            wp_reset_postdata();
        else :
            get_template_part( 'template-parts/loop/none' );
        endif;
        ?>
    </div>
</main>

<?php get_footer(); ?>

<?php
/**
 * Template Name: Trang Liên hệ
 * Template Post Type: page
 */
get_header(); ?>

<main id="primary" class="site-main page-contact container">
    <div class="contact-grid">

            <h1><?php the_title(); ?></h1>
            <p><strong>Địa chỉ:</strong> 123 Đường ABC, Quận 1, TP. HCM</p>
            <p><strong>Hotline:</strong> <a href="tel:0901234567"><?php echo esc_html( ten_field( 'hotline' ) ?: '090 123 4567' ); ?></a></p>
            <p><strong>Email:</strong> <a href="mailto:contact@domain.com">contact@domain.com</a></p>
            <div class="map-embed">
                <iframe src="https://maps.google.com/..." width="100%" height="280" style="border:0;" loading="lazy"></iframe>
            </div>

        </div>
    </div>
</main>

<?php get_footer(); ?>
