Tạo Page cứng

Tài liệu kỹ thuật: Cơ chế nạp template trang tĩnh của WordPress và hướng dẫn chi tiết cách tạo trang theo từng phương pháp.

I. Cơ chế hoạt động của WordPress với Page

1. Thứ tự tìm kiếm file template (Template Hierarchy)

Khi có yêu cầu truy cập vào một trang tĩnh (post type: page), WordPress sẽ quét file theo thứ tự ưu tiên từ trên xuống dưới và dừng lại ngay khi gặp file đầu tiên tồn tại:

1. Template được chọn tay trong Admin (templates/*.php)  [Ưu tiên cao nhất]
   ↓ (nếu trang để "Giao diện mặc định")
2. page-{slug}.php  (Tìm theo slug URL, ví dụ: page-gioi-thieu.php)
   ↓ (nếu không có)
3. page-{id}.php    (Tìm theo ID bài viết, ví dụ: page-42.php)
   ↓ (nếu không có)
4. page.php         (Template trang tĩnh dùng chung)
   ↓ (nếu không có)
5. singular.php     (Dự phòng chung cho cả post và page)
   ↓ (nếu không có)
6. index.php        [Lưới an toàn cuối cùng của theme]
Ngoại lệ cho Trang chủ: Nếu trang được cấu hình làm Trang chủ tĩnh trong Settings → Reading, WordPress luôn ưu tiên nạp file front-page.php trước tất cả các file trên.

2. So sánh cơ chế giữa Page Template và Slug Template

Tiêu chí Page Template (Chọn tay) Slug Template (Theo URL)
Cơ chế nhận diện Quét comment Template Name: ở đầu file và đọc giá trị meta _wp_page_template trong database. Khớp trực tiếp tên file với chuỗi slug (đường dẫn URL) của trang.
Vị trí lưu file Thư mục con templates/ hoặc thư mục gốc theme. Thư mục gốc theme (hoặc thư mục page/ nếu dùng loader).
Ảnh hưởng khi đổi URL Không ảnh hưởng: Đổi slug URL thì template vẫn giữ nguyên. Mất giao diện: Đổi slug URL là mất template, rơi về page.php.
Khả năng tái sử dụng Một template có thể gán cho nhiều trang khác nhau. Chỉ áp dụng cho đúng 1 trang có slug đó.

II. Hướng dẫn cách tạo chi tiết

Cách 1: Tạo bằng Page Template trong thư mục templates/ (Khuyên dùng)

  1. Tạo file mới trong thư mục templates/ (ví dụ: templates/page-gioi-thieu.php).
  2. Thêm comment khai báo tên template ở dòng đầu file: 
    <?php
/*
 * Template Name: Trang Giới thiệu
 */
get_header(); ?>
  3. Vào WP Admin → Pages → Thêm trang mới (hoặc sửa trang có sẵn).
  4. Tại cột bên phải, tìm mục Page Attributes (Thuộc tính trang) → Template (Giao diện), chọn "Trang Giới thiệu".
  5. Nhấn Publish (Đăng) hoặc Update (Cập nhật).

Cách 2: Tạo tự động theo Slug (page-{slug}.php)

  1. Vào WP Admin → Pages, xác định chính xác Đường dẫn (Slug) của trang (ví dụ: slug là lien-he).
  2. Tạo file theo cú pháp page-{slug}.php đặt tại thư mục gốc theme (hoặc page/page-{slug}.php nếu dùng loader): 
    ten-theme/page-lien-he.php
  3. Viết code cho file (không cần comment Template Name:). WordPress sẽ tự động kích hoạt file này mỗi khi người dùng truy cập link domain.com/lien-he/.

Cách 3: Tạo Trang chủ (Front Page)

  1. Tạo file front-page.php (hoặc page/front-page.php) ở theme.
  2. Vào Pages → Add New tạo trang có tên "Trang chủ" (slug: trang-chu).
  3. Vào Settings → Reading (Cài đặt → Đọc):
    • Tại Your homepage displays: chọn A static page.
    • Mục Homepage: chọn trang Trang chủ vừa tạo.

III. Sườn code mẫu (Boilerplate) - Copy dán dùng ngay

Sườn chuẩn mực cho mọi file template trang tĩnh, đã tích hợp đầy đủ header, footer, The Loop và các vị trí ghép section:

<?php
/**
 * Template Name: [Điền tên trang hiển thị trong Admin]
 * Description: Template trang tĩnh chuyên dụng
 */

// 1. Nạp Header
get_header(); ?>

<!-- 2. Thẻ bao bọc trang chính (có class động theo slug để viết CSS scoped) -->
<main id="primary" class="site-main page-custom page-<?php echo esc_attr( $post->post_name ?? 'custom' ); ?>">

    <?php
    // 3. Vòng lặp WordPress Loop chuẩn
    while ( have_posts() ) :
        the_post(); ?>

        <!-- Khối Banner / Tiêu đề -->
        <header class="page-header container">
            <h1 class="page-title"><?php the_title(); ?></h1>
            <?php if ( has_excerpt() ) : ?>
                <div class="page-lead lead"><?php echo get_the_excerpt(); ?></div>
            <?php endif; ?>
        </header>

        <!-- Nội dung editor nhập từ Admin (nếu có) -->
        <?php if ( get_the_content() ) : ?>
            <div class="page-entry-content container">
                <?php the_content(); ?>
            </div>
        <?php endif; ?>

        <!-- Các khối Section ghép từ template-parts -->
        <div class="page-sections">
            <?php
            // get_template_part( 'template-parts/section/intro' );
            // get_template_part( 'template-parts/section/services' );
            // get_template_part( 'template-parts/section/cta' );
            ?>
        </div>

    <?php
    endwhile; // Kết thúc Loop
    ?>

</main>

<?php
// 4. Nạp Footer
get_footer();
?>

IV. Những lưu ý quan trọng về cách dùng The Loop

Cú pháp while ( have_posts() ) : the_post(); là vòng lặp tiêu chuẩn (The Loop) của WordPress. Khi code Page cứng, bạn cần nắm vững các nguyên tắc sau:

1. Tại sao trang đơn chỉ có 1 bài mà vẫn cần vòng lặp while?
Ở trang đơn (Page hoặc Single), vòng lặp while này chỉ chạy đúng 1 lần duy nhất. Mục đích then chốt nằm ở hàm the_post(): nó khởi tạo đối tượng trang hiện tại và nạp dữ liệu vào biến toàn cục $post.
Tình huống Có cần The Loop không? Giải thích chi tiết
Trang có xuất dữ liệu động Bắt buộc dùng Để các hàm the_title(), the_content(), the_post_thumbnail() và get_the_ID() (dùng lấy Custom Field) nhận diện chính xác dữ liệu của trang hiện tại.
Trang có dùng Plugin SEO & Shortcode Bắt buộc dùng Plugin SEO (Yoast, Rank Math) và các shortcode (Contact Form 7...) hoạt động dựa trên hook của the_post() để tính toán điểm SEO, tạo Canonical URL và lấy ID bài.
Landing Page thuần HTML tĩnh 100% Có thể bỏ Nếu toàn bộ trang được viết bằng mã HTML cố định, không dùng bất kỳ hàm WordPress nào, bạn có thể lược bỏ The Loop mà trang vẫn chạy bình thường.

2. Lưu ý tối quan trọng khi có vòng lặp phụ (Custom Query)

Khi trong Page cứng có truy vấn thêm dữ liệu khác (ví dụ: lấy 4 thành viên đội ngũ hoặc 3 tin tức mới nhất bằng new WP_Query()):

  • Vòng lặp phụ sẽ ghi đè biến $post của trang chính.
  • Bắt buộc phải gọi hàm wp_reset_postdata(); ngay sau khi kết thúc vòng lặp phụ để khôi phục lại dữ liệu của Trang chính:
<?php
$custom_query = new WP_Query( array(
    'post_type'      => 'tin-tuc',
    'posts_per_page' => 3,
) );

if ( $custom_query->have_posts() ) :
    while ( $custom_query->have_posts() ) : $custom_query->the_post();
        // Lặp qua từng tin tức
        the_title();
    endwhile;

    // BẮT BUỘC: Khôi phục lại ngữ cảnh $post của trang chính!
    wp_reset_postdata();
endif;
?>

Nếu quên wp_reset_postdata(), toàn bộ các hàm ở phía sau (như Footer, widget, Custom Fields của trang chính) sẽ nhận nhầm ID của bài viết cuối cùng trong vòng lặp phụ.

V. Ví dụ ứng dụng thực tế

1. Trang chủ (front-page.php)

<?php
/**
 * Template Name: Trang chủ
 */
get_header(); ?>

<main id="primary" class="site-main front-page">
    <?php
    get_template_part( 'template-parts/section/hero' );
    get_template_part( 'template-parts/section/intro' );
    get_template_part( 'template-parts/section/services' );
    get_template_part( 'template-parts/section/stats' );
    get_template_part( 'template-parts/section/cta' );
    get_template_part( 'template-parts/section/latest-news' );
    ?>
</main>

<?php get_footer(); ?>

2. Trang Đội ngũ (templates/page-team.php)

<?php
/**
 * Template Name: Trang Đội ngũ
 */
get_header(); ?>

<main id="primary" class="site-main page-team container">
    <header class="team-header text-center">
        <h1><?php the_title(); ?></h1>
        <p class="lead">Đội ngũ nhân sự chuyên môn cao của công ty.</p>
    </header>

    <div class="team-grid">
        <?php
        $team_query = new WP_Query( array(
            'post_type'      => 'thanh-vien',
            'posts_per_page' => -1,
            'orderby'        => 'menu_order',
            'order'          => 'ASC',
        ) );

        if ( $team_query->have_posts() ) :
            while ( $team_query->have_posts() ) : $team_query->the_post();
                get_template_part( 'template-parts/loop/card', 'thanh-vien' );
            endwhile;
            wp_reset_postdata();
        else :
            get_template_part( 'template-parts/loop/none' );
        endif;
        ?>
    </div>
</main>

<?php get_footer(); ?>

3. Trang Liên hệ (templates/page-contact.php)

/**

 */
get_header(); ?>

<main id="primary" class="site-main page-contact container">

            <p><strong>Hotline:</strong> <a href="tel:0901234567">090 123 4567</a></p>
            <p><strong>Email:</strong> <a href="mailto:contact@domain.com">contact@domain.com</a></p>
            <div class="map-embed">
                <iframe src="https://maps.google.com/..." width="100%" height="280" style="border:0;" loading="lazy"></iframe>
            </div>
        </div>

        <div class="contact-form-box">
            <h2>Gửi thông tin liên hệ</h2>
            <?php echo do_shortcode( '[contact-form-7 id="12" title="Form liên hệ"]' ); ?>
        </div>
    </div>
</main>

<?php get_footer(); ?>
