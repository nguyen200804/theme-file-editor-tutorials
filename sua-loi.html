Xử lý sự cố

Một số lỗi phổ biến khi tùy biến theme trong Theme File Editor và cách khắc phục nhanh chóng.

Template mới không chạy

Kiểm tra tên file khớp key (không phải label), đã nạp template-loader.php chưa, rồi vào Settings → Permalinks → Save Changes để làm mới đường dẫn. Hãy xóa cache nếu site đang dùng plugin cache.

Không biết trang đang dùng file nào

Cài plugin Query Monitor và xem mục Template: nó liệt kê cả danh sách file ứng viên WordPress đã thử theo thứ tự ưu tiên.

Page Template không xuất hiện trong danh sách chọn

Kiểm tra comment Template Name: ở đầu file, đảm bảo file nằm trong thư mục gốc hoặc thư mục templates/. Nếu vẫn không thấy, thử đổi sang theme khác rồi kích hoạt lại để WordPress làm mới danh sách template.

Site trắng (WSOD) sau khi sửa functions.php

Lỗi cú pháp PHP. Bạn cần mở và sửa lại file qua FTP hoặc cPanel File Manager, hoặc khôi phục lại bản sao lưu trước đó.
