Đăng ký Post Type, Taxonomy và Option Page

Cách mở rộng cấu trúc dữ liệu cho WordPress: tạo các loại bài viết mới (Dự án, Sản phẩm), các nhóm phân loại tùy biến và trang cấu hình chung toàn site bằng mã nguồn PHP gốc.

1. Đăng ký Custom Post Type (CPT)

Dùng hàm register_post_type() móc vào hook init. Tạo file tại inc/custom-post-types.php:

Các tham số cốt lõi cần nhớ:

Tham số Ý nghĩa & Giá trị khuyên dùng
labels Mảng tên hiển thị trong Admin (Tên menu, Thêm mới, Sửa bài...).
public true để bài viết hiển thị ra ngoài website và có giao diện quản trị.
has_archive true để kích hoạt trang danh sách (ví dụ: domain.com/du-an/).
rewrite array('slug' => 'du-an') định nghĩa đường dẫn URL tĩnh.
supports Các tính năng bật cho bài viết: title, editor, thumbnail, excerpt...
menu_icon Icon menu Admin (lấy từ WordPress Dashicons).
show_in_rest true nếu muốn dùng trình soạn thảo khối Gutenberg; false để dùng Classic Editor.

Code mẫu: Đăng ký Post Type "Dự án" (du-an)

<?php
// inc/custom-post-types.php
function ten_register_custom_post_types() {
    $labels = array(
        'name'               => 'Dự án',
        'singular_name'      => 'Dự án',
        'menu_name'          => 'Dự án',
        'add_new'            => 'Thêm dự án',
        'add_new_item'       => 'Thêm dự án mới',
        'edit_item'          => 'Chỉnh sửa dự án',
        'new_item'           => 'Dự án mới',
        'view_item'          => 'Xem dự án',
        'search_items'       => 'Tìm kiếm dự án',
        'not_found'          => 'Không tìm thấy dự án nào',
        'not_found_in_trash' => 'Thùng rác trống',
    );

    $args = array(
        'labels'              => $labels,
        'public'              => true,
        'has_archive'         => true,            // Bắt buộc bật để có trang /du-an/
        'publicly_queryable'  => true,
        'query_var'           => true,
        'rewrite'             => array( 'slug' => 'du-an', 'with_front' => false ),
        'capability_type'     => 'post',
        'hierarchical'        => false,
        'menu_position'       => 5,               // Đặt ngay dưới mục Bài viết
        'menu_icon'           => 'dashicons-portfolio', // Icon portfolio
        'supports'            => array( 'title', 'editor', 'thumbnail', 'excerpt' ),
        'show_in_rest'        => false,           // Đổi thành true nếu muốn dùng Gutenberg
    );

    register_post_type( 'du-an', $args );
}
add_action( 'init', 'ten_register_custom_post_types' );
LƯU Ý BẮT BUỘC: Sau khi thêm hoặc đổi slug Post Type, bạn phải vào Settings → Permalinks (Cài đặt → Đường dẫn tĩnh) và nhấn "Save Changes" (Lưu thay đổi) để cập nhật rewrite rule, nếu không vào /du-an/ sẽ bị lỗi 404!

2. Đăng ký Custom Taxonomy (Phân loại tùy biến)

Dùng hàm register_taxonomy() móc vào hook init để tạo chuyên mục riêng cho Post Type. Tạo file tại inc/custom-taxonomies.php:

Tham số quan trọng: hierarchical

  • 'hierarchical' => true: Hoạt động giống Chuyên mục (Category) — có phân cấp Cha / Con và tích chọn checkbox.
  • 'hierarchical' => false: Hoạt động giống Thẻ (Tag) — gõ chữ và gắn tag bằng dấu phẩy.

Code mẫu: Đăng ký "Loại dự án" (loai-du-an) cho Post Type "du-an"

<?php
// inc/custom-taxonomies.php
function ten_register_custom_taxonomies() {
    $labels = array(
        'name'              => 'Loại dự án',
        'singular_name'     => 'Loại dự án',
        'search_items'      => 'Tìm kiếm loại dự án',
        'all_items'         => 'Tất cả loại dự án',
        'parent_item'       => 'Loại dự án cha',
        'parent_item_colon' => 'Loại dự án cha:',
        'edit_item'         => 'Chỉnh sửa loại dự án',
        'update_item'       => 'Cập nhật loại dự án',
        'add_new_item'      => 'Thêm loại dự án mới',
        'new_item_name'     => 'Tên loại dự án mới',
        'menu_name'         => 'Loại dự án',
    );

    $args = array(
        'hierarchical'      => true,                      // Dạng danh mục có cha/con
        'labels'            => $labels,
        'show_ui'           => true,
        'show_admin_column' => true,                      // Hiện cột chuyên mục trong danh sách bài Admin
        'query_var'         => true,
        'rewrite'           => array( 'slug' => 'loai-du-an', 'with_front' => false ),
        'show_in_rest'      => false,
    );

    // Gắn taxonomy này vào post type 'du-an'
    register_taxonomy( 'loai-du-an', array( 'du-an' ), $args );
}
add_action( 'init', 'ten_register_custom_taxonomies' );

3. Đăng ký Option Page (Trang cài đặt Theme)

Tạo một trang riêng trong thanh menu Admin để lưu cấu hình chung (Hotline, Email, Bản quyền...). Tạo file tại inc/options-page.php:

Code mẫu hoàn chỉnh dùng Settings API của WordPress:

<?php
// inc/options-page.php

// 1. Tạo Menu trong Admin
function ten_register_theme_options_menu() {
    add_menu_page(
        'Cài đặt Website',             // Tiêu đề trang
        'Cài đặt Theme',               // Tên hiển thị trên Menu
        'manage_options',              // Quyền truy cập (chỉ Admin)
        'theme-settings',              // Slug menu
        'ten_render_theme_options_page', // Hàm vẽ giao diện form
        'dashicons-admin-generic',     // Icon bánh răng
        60                             // Vị trí menu
    );
}
add_action( 'admin_menu', 'ten_register_theme_options_menu' );

// 2. Đăng ký nhóm cài đặt với WordPress (Lưu vào bảng wp_options)
function ten_register_theme_settings() {
    register_setting( 'theme_options_group', 'theme_options' );
}
add_action( 'admin_init', 'ten_register_theme_settings' );

// 3. Hàm vẽ giao diện Form cài đặt
function ten_render_theme_options_page() {
    $options = get_option( 'theme_options', array() );
    ?>
    <div class="wrap">
        <h1>Cài đặt chung Website</h1>
        <form method="post" action="options.php">
            <?php
            settings_fields( 'theme_options_group' );
            ?>
            <table class="form-table">
                <tr>
                    <th scope="row"><label for="hotline">Số Hotline</label></th>
                    <td>
                        <input type="text" id="hotline" name="theme_options[hotline]" 
                               value="<?php echo esc_attr( $options['hotline'] ?? '' ); ?>" class="regular-text">
                    </td>
                </tr>
                <tr>
                    <th scope="row"><label for="email">Email liên hệ</label></th>
                    <td>
                        <input type="email" id="email" name="theme_options[email]" 
                               value="<?php echo esc_attr( $options['email'] ?? '' ); ?>" class="regular-text">
                    </td>
                </tr>
                <tr>
                    <th scope="row"><label for="footer_copy">Bản quyền Footer</label></th>
                    <td>
                        <input type="text" id="footer_copy" name="theme_options[footer_copy]" 
                               value="<?php echo esc_attr( $options['footer_copy'] ?? '' ); ?>" class="large-text">
                    </td>
                </tr>
            </table>
            <?php submit_button( 'Lưu thay đổi' ); ?>
        </form>
    </div>
    <?php
}

// 4. Hàm helper gọi nhanh ngoài Frontend
function ten_get_option( $key, $default = '' ) {
    $options = get_option( 'theme_options', array() );
    return $options[$key] ?? $default;
}

Cách gọi dữ liệu ngoài template (header.php, footer.php):

<!-- Lấy số Hotline trong header.php -->
<a href="tel:<?php echo esc_attr( ten_get_option( 'hotline' ) ); ?>">
    <?php echo esc_html( ten_get_option( 'hotline' ) ); ?>
</a>

<!-- Lấy bản quyền trong footer.php -->
<p>&copy; <?php echo esc_html( ten_get_option( 'footer_copy' ) ); ?></p>
