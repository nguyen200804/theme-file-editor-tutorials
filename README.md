# Theme File Editor Tutorials

Tài liệu hướng dẫn cấu hình và phát triển Classic Theme WordPress thông qua Theme File Editor (hoặc code trực tiếp).

## Cấu trúc các trang

1. **[Bắt đầu](index.html)**: Yêu cầu tối thiểu, cách chỉnh sửa và lưu ý sao lưu.
2. **[Cấu trúc thư mục](cau-truc.html)**: Sắp xếp các thư mục và tập tin chuẩn trong theme.
3. **[Thứ tự chọn template](thu-tu.html)**: Template hierarchy trong WordPress từ chi tiết đến tổng quát.
4. **[Gom file vào folder](loader.html)**: Tạo template loader đưa file vào các thư mục con `page/`, `single/`, `archive/`.
5. **[Template parts](template-parts.html)**: Bóc tách khối giao diện thành các thành phần tái sử dụng.
6. **[Tạo Page cứng](page-cung.html)**: Hướng dẫn tạo trang chủ (`front-page.php`), trang giới thiệu, trang đội ngũ và trang liên hệ.
7. **[Đăng ký Post Type, Taxonomy, Option](dang-ky-post-type.html)**: Cách đăng ký Custom Post Type, Custom Taxonomy và Option Page chuẩn WordPress.
8. **[Tạo Template Archive](archive.html)**: Hướng dẫn tạo template lưu trữ danh sách (chuyên mục, thẻ, taxonomy và custom post type).
9. **[Tạo Template Single Post-type](single.html)**: Hướng dẫn tạo template trang chi tiết (bài viết, sản phẩm, dự án, custom fields, bài liên quan).
10. **[Custom field thay ACF](fields.html)**: Bộ khung meta box thuần thay thế ACF để quản lý dữ liệu linh hoạt.
11. **[Tra cứu kiểu field](tra-cuu-field.html)**: Bảng tra cứu 15 kiểu field thông dụng: cú pháp khai báo, cách lấy dữ liệu và code mẫu template.
12. **[Xử lý sự cố](sua-loi.html)**: Các lỗi thường gặp và cách khắc phục.
