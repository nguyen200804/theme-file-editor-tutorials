# Theme File Editor Tutorials

Tài liệu hướng dẫn cấu hình và phát triển Classic Theme WordPress thông qua Theme File Editor (hoặc code trực tiếp).

## Cấu trúc các trang

1. **[Danh sách bài viết](index.html)**: Trang chủ và mục lục toàn bộ các bài viết hướng dẫn.
2. **[Cấu trúc thư mục](cau-truc.html)**: Sắp xếp các thư mục và tập tin chuẩn trong theme.
3. **[Thứ tự chọn template](thu-tu.html)**: Template hierarchy trong WordPress từ chi tiết đến tổng quát.
4. **[Gom file vào folder](loader.html)**: Tạo template loader đưa file vào các thư mục con `page/`, `single/`, `archive/`.
5. **[Template parts](template-parts.html)**: Bóc tách khối giao diện thành các thành phần tái sử dụng.
6. **[Tạo Header, Footer & Gọi Menu](header-footer-menu.html)**: Các hook bắt buộc (wp_head, wp_footer), cấu trúc header.php / footer.php và gọi menu wp_nav_menu.
7. **[Tạo Page cứng](page-cung.html)**: Hướng dẫn tạo trang chủ (`front-page.php`), trang giới thiệu, trang đội ngũ và trang liên hệ.
8. **[Khi nào dùng The Loop](the-loop.html)**: Giải mã vòng lặp `while ( have_posts() ) : the_post();`, trường hợp bắt buộc và khi nào có thể bỏ qua.
9. **[Đăng ký Post Type, Taxonomy, Option](dang-ky-post-type.html)**: Cách đăng ký Custom Post Type, Custom Taxonomy và Option Page chuẩn WordPress.
10. **[Tạo Loop Item](loop-item.html)**: Hướng dẫn tạo thẻ hiển thị (Card) cho bài viết, custom post type và taxonomy.
11. **[Tạo Template Archive](archive.html)**: Hướng dẫn tạo template lưu trữ danh sách (chuyên mục, thẻ, taxonomy và custom post type).
12. **[Custom UI Pagination](pagination.html)**: Tùy biến giao diện phân trang chuẩn WordPress, bóc tách component trong `template-parts/ui/`.
13. **[Tạo Template Single Post-type](single.html)**: Hướng dẫn tạo template trang chi tiết (bài viết, sản phẩm, dự án, custom fields, bài liên quan).
14. **[Custom field thay ACF](fields.html)**: Bộ khung meta box thuần thay thế ACF để quản lý dữ liệu linh hoạt.
15. **[Tra cứu kiểu field](tra-cuu-field.html)**: Bảng tra cứu 15 kiểu field thông dụng: cú pháp khai báo, cách lấy dữ liệu và code mẫu template.
16. **[Tra cứu hàm lấy dữ liệu](tra-cuu-du-lieu.html)**: Bảng tra cứu các hàm WordPress lấy ảnh, danh mục, ngày giờ, trích dẫn, link và custom fields.
17. **[Xử lý sự cố](sua-loi.html)**: Các lỗi thường gặp và cách khắc phục.
