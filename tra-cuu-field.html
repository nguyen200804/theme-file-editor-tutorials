Tra cứu các kiểu Custom Field

Bảng tra cứu nhanh cú pháp khai báo (Config) và code mẫu xuất dữ liệu (Template) cho từng kiểu trường trong bộ khung thay thế ACF.

Bảng tra cứu nhanh

Kiểu (type) Mô tả Hàm lấy dữ liệu Hàm Escape an toàn
text Chuỗi văn bản ngắn 1 dòng ten_field('key') esc_html() / esc_attr()
textarea Văn bản nhiều dòng ten_field('key') nl2br( esc_html(...) )
number Số nguyên hoặc số thập phân ten_field('key') number_format_i18n()
email Địa chỉ email chuẩn ten_field('key') esc_html() / antispambot()
url Đường dẫn liên kết ten_field('key') esc_url()
select Menu thả xuống chọn 1 giá trị ten_field('key') esc_html()
radio Nút chọn 1 trong nhiều lựa chọn ten_field('key') esc_html()
checkbox Hộp đánh dấu Bật/Tắt ('1' hoặc '0') ten_field('key') Kiểm tra if ('1' === ...)
image Chọn 1 ảnh từ thư viện Media ten_image('key', 'size') Tự động in thẻ <img> chuẩn
gallery Chọn nhiều ảnh làm Album/Slider ten_gallery('key') Trả về mảng các Attachment ID
color Hộp chọn mã màu (#hex) ten_field('key') esc_attr()
date Bộ chọn ngày tháng (YYYY-MM-DD) ten_field('key') date_i18n()
file Tập tin đính kèm (PDF, DOCX, ZIP) ten_field('key') wp_get_attachment_url()
wysiwyg Bộ soạn thảo văn bản chuẩn WordPress ten_field('key') wp_kses_post()
repeater Danh sách lặp nhiều hàng (sub-fields) ten_field('key') Vòng lặp foreach

1. text (Văn bản ngắn)

Dùng cho họ tên, chức danh, mã sản phẩm, tiêu đề phụ.

// Khai báo:
array( 'key' => 'ma_san_pham', 'label' => 'Mã sản phẩm (SKU)', 'type' => 'text' )

// Sử dụng trong template:
<?php echo esc_html( ten_field( 'ma_san_pham' ) ); ?>

2. textarea (Văn bản nhiều dòng)

Dùng cho mô tả ngắn, địa chỉ, mã nhúng script, ghi chú.

// Khai báo:
array( 'key' => 'ghi_chu', 'label' => 'Ghi chú đơn hàng', 'type' => 'textarea' )

// Sử dụng trong template (giữ xuống dòng):
<?php echo nl2br( esc_html( ten_field( 'ghi_chu' ) ) ); ?>

3. number (Số)

Dùng cho giá bán, diện tích, năm hoàn thành, số lượng.

// Khai báo:
array( 'key' => 'gia_ban', 'label' => 'Giá bán (VNĐ)', 'type' => 'number' )

// Sử dụng trong template (định dạng dấu phẩy phân cách ngàn):
<?php echo esc_html( number_format_i18n( ten_field( 'gia_ban' ) ) ); ?> đ

4. email (Địa chỉ thư điện tử)

Dùng cho email liên hệ, email hỗ trợ kỹ thuật.

// Khai báo:
array( 'key' => 'email_lien_he', 'label' => 'Email hỗ trợ', 'type' => 'email' )

// Sử dụng trong template:
<a href="mailto:<?php echo esc_attr( ten_field( 'email_lien_he' ) ); ?>">
    <?php echo esc_html( ten_field( 'email_lien_he' ) ); ?>
</a>

5. url (Đường dẫn liên kết)

Dùng cho link mạng xã hội, link landing page ngoài, link video youtube.

// Khai báo:
array( 'key' => 'link_video', 'label' => 'Link Youtube', 'type' => 'url' )

// Sử dụng trong template:
<a href="<?php echo esc_url( ten_field( 'link_video' ) ); ?>" target="_blank" rel="noopener">Xem Video</a>

6. select (Menu thả xuống)

Dùng khi cần chọn 1 giá trị cố định từ danh sách có sẵn.

// Khai báo:
array(
    'key'     => 'tinh_trang',
    'label'   => 'Tình trạng hàng',
    'type'    => 'select',
    'options' => array(
        'con_hang' => 'Còn hàng',
        'het_hang' => 'Hết hàng',
        'dat_truoc'=> 'Đặt trước',
    ),
)

// Sử dụng trong template:
<?php
$status = ten_field( 'tinh_trang' );
if ( 'con_hang' === $status ) {
    echo '<span class="badge in-stock">Còn hàng</span>';
}
?>

7. radio (Nút chọn duy nhất)

Tương tự select nhưng hiển thị toàn bộ lựa chọn ra màn hình để click nhanh.

// Khai báo:
array(
    'key'     => 'bo_cuc',
    'label'   => 'Kiểu bố cục banner',
    'type'    => 'radio',
    'options' => array(
        'full'   => 'Toàn màn hình',
        'box'    => 'Đóng khung gọn',
    ),
)

8. checkbox (Hộp kiểm Bật / Tắt)

Dùng cho các cờ nhị phân: "Nổi bật", "Ghim đầu trang", "Ẩn giá". Lưu giá trị '1' hoặc '0'.

// Khai báo:
array( 'key' => 'noi_bat', 'label' => 'Đánh dấu nổi bật', 'type' => 'checkbox' )

// Sử dụng trong template:
<?php if ( '1' === ten_field( 'noi_bat' ) ) : ?>
    <span class="badge hot">HOT</span>
<?php endif; ?>

9. image (Ảnh đơn)

Tích hợp cửa sổ Media Library của WordPress. Lưu trữ Attachment ID.

// Khai báo:
array( 'key' => 'anh_dai_dien', 'label' => 'Ảnh đại diện', 'type' => 'image' )

// Cách 1: Xuất nhanh cả thẻ <img> chuẩn WordPress:
<?php echo ten_image( 'anh_dai_dien', 'large' ); ?>

// Cách 2: Lấy riêng URL của ảnh:
<?php
$img_id = ten_field( 'anh_dai_dien' );
$img_url = wp_get_attachment_image_url( $img_id, 'full' );
?>
<img src="<?php echo esc_url( $img_url ); ?>" alt="Ảnh">

10. gallery (Bộ sưu tập ảnh)

Cho phép chọn nhiều ảnh cùng lúc, sắp xếp kéo thả. Lưu mảng các Attachment ID.

// Khai báo:
array( 'key' => 'album_anh', 'label' => 'Album ảnh dự án', 'type' => 'gallery' )

// Sử dụng trong template:
<div class="slider-gallery">
    <?php
    $gallery_ids = ten_gallery( 'album_anh' );
    foreach ( (array) $gallery_ids as $id ) : ?>
        <div class="slide-item">
            <?php echo wp_get_attachment_image( $id, 'large' ); ?>
        </div>
    <?php endforeach; ?>
</div>

11. color (Mã màu sắc)

Mở bảng màu (Color Picker). Trả về chuỗi mã màu hex (ví dụ #ff0000).

// Khai báo:
array( 'key' => 'mau_nen', 'label' => 'Màu nền khối', 'type' => 'color' )

// Sử dụng trong template:
<div style="background-color: <?php echo esc_attr( ten_field( 'mau_nen' ) ); ?>;">...</div>

12. date (Ngày tháng)

Hộp chọn lịch ngày/tháng/năm theo định dạng chuẩn YYYY-MM-DD.

// Khai báo:
array( 'key' => 'ngay_khoi_chieu', 'label' => 'Ngày khởi chiếu', 'type' => 'date' )

// Sử dụng trong template:
<?php
$date_raw = ten_field( 'ngay_khoi_chieu' );
if ( $date_raw ) {
    echo esc_html( date_i18n( 'd/m/Y', strtotime( $date_raw ) ) );
}
?>

13. file (Tập tin đính kèm)

Upload tài liệu PDF, DOCX, ZIP qua Media Library. Lưu Attachment ID.

// Khai báo:
array( 'key' => 'tai_lieu_dinh_kem', 'label' => 'Tài liệu hướng dẫn (PDF)', 'type' => 'file' )

// Sử dụng trong template:
<?php
$file_id  = ten_field( 'tai_lieu_dinh_kem' );
$file_url = wp_get_attachment_url( $file_id );
if ( $file_url ) : ?>
    <a href="<?php echo esc_url( $file_url ); ?>" download>Tải về tài liệu (.PDF)</a>
<?php endif; ?>

14. wysiwyg (Trình soạn thảo phong phú)

Nhúng khung soạn thảo TinyMCE đầy đủ (đậm, nghiêng, chèn ảnh, căn lề).

// Khai báo:
array( 'key' => 'noi_dung_phu', 'label' => 'Nội dung mở rộng', 'type' => 'wysiwyg' )

// Sử dụng trong template:
<div class="rich-content">
    <?php echo wp_kses_post( ten_field( 'noi_dung_phu' ) ); ?>
</div>

15. repeater (Trường lặp danh sách)

Cho phép bấm nút "Thêm hàng" để nhập vô số dòng dữ liệu có cấu trúc giống nhau.

// Khai báo:
array(
    'key'        => 'bang_gia',
    'label'      => 'Bảng giá dịch vụ',
    'type'       => 'repeater',
    'sub_fields' => array(
        array( 'key' => 'ten_goi',  'label' => 'Tên gói dịch vụ', 'type' => 'text' ),
        array( 'key' => 'muc_gia',  'label' => 'Mức giá',         'type' => 'number' ),
        array( 'key' => 'mo_ta',    'label' => 'Mô tả ngắn',      'type' => 'text' ),
    ),
)

// Sử dụng trong template:
<table>
    <tr><th>Gói</th><th>Giá</th><th>Mô tả</th></tr>
    <?php foreach ( (array) ten_field( 'bang_gia' ) as $row ) : ?>
        <tr>
            <td><?php echo esc_html( $row['ten_goi'] ); ?></td>
            <td><?php echo esc_html( number_format_i18n( $row['muc_gia'] ) ); ?> đ</td>
            <td><?php echo esc_html( $row['mo_ta'] ); ?></td>
        </tr>
    <?php endforeach; ?>
</table>
