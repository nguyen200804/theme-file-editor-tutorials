Hướng dẫn chi tiết từ A-Z: Tạo Header, Footer và Quản lý Menu trong WordPress

Tài liệu toàn diện giải thích bản chất từng dòng code trong header.php, footer.php, quy chế hoạt động của Menu WordPress và cách xử lý các lỗi thường gặp cho người mới bắt đầu.

I. Hiểu đúng bản chất của Header và Footer trong WordPress

Một trang web hoàn chỉnh luôn bắt đầu bằng thẻ khai báo <!DOCTYPE html> và kết thúc bằng thẻ đóng </html>. Trong kiến trúc theme WordPress, cấu trúc này được chia đôi làm 2 nửa độc lập kẹp lấy nội dung ở giữa:

  • header.php (Nửa trên): Mở thẻ <html>, thẻ <head>, nạp mã CSS/SEO, mở thẻ <body>, chứa khối Logo và Thanh Menu điều hướng chính.
  • Các file nội dung (Ở giữa): Như front-page.php, page.php, single.php, archive.php... chỉ chứa phần ruột <main> của riêng trang đó.
  • footer.php (Nửa dưới): Chứa nội dung chân trang, thông tin bản quyền, nạp mã JavaScript, và quan trọng nhất là đóng lại hai thẻ </body> và </html>.

Nhờ cách chia module này, khi bạn muốn thay đổi Logo, thêm số Hotline hay chỉnh sửa Menu trên đầu trang, bạn chỉ cần sửa đúng 1 file header.php duy nhất là toàn bộ hàng trăm trang trên website đều tự động cập nhật đồng bộ.

II. 3 "Hàm sống còn" bắt buộc phải có trong Header & Footer

Rất nhiều người mới lập trình theme gặp phải các lỗi khó hiểu như: "Mất thanh Admin Bar màu đen trên cùng khi đã đăng nhập" hoặc "Cài plugin Contact Form 7, Yoast SEO nhưng không hoạt động". Nguyên nhân 100% là do thiếu 3 hàm hook cốt lõi sau:

Hàm Hook Vị trí đặt bắt buộc Chức năng thực tế
wp_head(); Đặt ngay TRƯỚC thẻ đóng </head> trong header.php Là nơi WordPress và các plugin tự động bơm mã CSS, mã thẻ meta SEO, Favicon và mã Google Analytics vào đầu trang.
wp_body_open(); Đặt ngay SAU thẻ mở <body> trong header.php Dành cho các mã theo dõi cần kích hoạt ngay khi mở thẻ body (như mã Google Tag Manager dạng noscript).
wp_footer(); Đặt ngay TRƯỚC thẻ đóng </body> trong footer.php Là nơi nạp toàn bộ các file JavaScript (.js), thư viện jQuery, mã popup và thanh công cụ quản trị (Admin Bar).

III. Chi tiết từng dòng code trong file header.php chuẩn

Dưới đây là mã nguồn header.php hoàn chỉnh kèm giải thích chi tiết ý nghĩa từng dòng code:

<!DOCTYPE html>
<!-- 1. language_attributes(): Tự động in ngôn ngữ của trang (ví dụ lang="vi" hoặc lang="en-US") -->
<html <?php language_attributes(); ?>>
<head>
    <!-- 2. bloginfo('charset'): Tự động in bảng mã UTF-8 chống lỗi font tiếng Việt -->
    <meta charset="<?php bloginfo( 'charset' ); ?>">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    
    <!-- 3. Hàm sống còn của Header (BẮT BUỘC) -->
    <?php wp_head(); ?>
</head>

<!-- 4. body_class(): Tự động in các class CSS nhận diện trang (VD: home, logged-in, page-id-10...) -->
<body <?php body_class(); ?>>
<?php wp_body_open(); ?>

<header class="site-header">
    <div class="container header-inner">
        
        <!-- KHỐI LOGO WEBSITE -->
        <div class="site-branding">
            <?php
            // Nếu khách hàng đã tải logo lên trong Giao diện -> Tùy biến thì in ảnh Logo:
            if ( has_custom_logo() ) :
                the_custom_logo();
            else :
                // Nếu chưa có logo, in tên website dạng chữ kèm link về trang chủ:
                ?>
                <a class="site-title" href="<?php echo esc_url( home_url( '/' ) ); ?>">
                    <?php bloginfo( 'name' ); ?>
                </a>
            <?php endif; ?>
        </div>

        <!-- KHỐI MENU CHÍNH -->
        <nav class="main-navigation" aria-label="Menu chính">
            <?php
            wp_nav_menu( array(
                'theme_location' => 'primary-menu', // Gắn với vị trí đã đăng ký
                'container'      => false,          // Bỏ thẻ <div> thừa bọc ngoài
                'menu_class'     => 'menu-list',     // Gán class CSS cho thẻ <ul>
                'fallback_cb'    => false,          // Không in bừa bãi khi chưa tạo menu
            ) );
            ?>
        </nav>

    </div>
</header>

IV. Chi tiết từng dòng code trong file footer.php chuẩn

Dưới đây là mã nguồn footer.php hoàn chỉnh, đóng kín các thẻ mở từ đầu trang:

<footer class="site-footer">
    <div class="container footer-inner">
        
        <!-- MENU PHỤ CHÂN TRANG (Chính sách, Điều khoản...) -->
        <nav class="footer-navigation" aria-label="Menu chân trang">
            <?php
            wp_nav_menu( array(
                'theme_location' => 'footer-menu',
                'container'      => false,
                'menu_class'     => 'footer-links',
                'depth'          => 1, // Chỉ lấy cấp cha, không xổ menu con
                'fallback_cb'    => false,
            ) );
            ?>
        </nav>

        <!-- BẢN QUYỀN TỰ ĐỘNG CẬP NHẬT NĂM HIỆN TẠI -->
        <div class="site-copyright">
            <p>
                &copy; <?php echo esc_html( date( 'Y' ) ); ?> 
                <?php bloginfo( 'name' ); ?>. Bảo lưu mọi quyền.
            </p>
        </div>

    </div>
</footer>

<!-- 5. Hàm sống còn của Footer: Nạp Javascript và Admin Bar (BẮT BUỘC) -->
<?php wp_footer(); ?>

<!-- Đóng lại các thẻ mở từ header.php -->
</body>
</html>

V. Cơ chế hoạt động của Menu trong WordPress (Hình dung đơn giản)

Để hiểu cách Menu vận hành một cách trực quan, bạn hãy tưởng tượng mô hình thực tế sau:

  • theme_location (Vị trí menu): Giống như "Chiếc móc treo áo cố định trên tường" do lập trình viên đóng sẵn trong mã code.
  • Menu trong Admin: Giống như "Chiếc áo" do khách hàng tự may (tự gom các liên kết Trang chủ, Giới thiệu, Sản phẩm...).
  • Hành động gán (Display location): Là hành động lấy "Chiếc áo" móc vào "Chiếc móc treo" tương ứng.

Quy trình thực hiện 3 bước rõ ràng:

Bước 1: Tạo móc treo trong code (functions.php)

Mở file functions.php và khai báo các vị trí bạn muốn đặt menu trên website:

function theme_setup_menus() {
    register_nav_menus( array(
        'primary-menu' => 'Menu Chính Đầu Trang',
        'footer-menu'  => 'Menu Chân Trang',
        'mobile-menu'  => 'Menu Trên Điện Thoại',
    ) );
}
add_action( 'after_setup_theme', 'theme_setup_menus' );

Bước 2: Tạo chiếc áo và móc vào trong Admin

  1. Đăng nhập WordPress Admin → vào mục Giao diện (Appearance) → Trình đơn (Menus).
  2. Nhập tên menu (Ví dụ: Menu Header) rồi bấm Tạo trình đơn.
  3. Cột bên trái: Tích chọn các trang (Trang chủ, Tin tức, Giới thiệu...) rồi bấm Thêm vào trình đơn.
  4. Kéo thả sắp xếp thứ tự hoặc kéo thụt vào trong để tạo menu đa cấp (Dropdown con).
  5. BƯỚC QUAN TRỌNG NHẤT: Ở mục Cài đặt trình đơn → Vị trí hiển thị (Display location), tích chọn vào "Menu Chính Đầu Trang".
  6. Bấm Lưu trình đơn.

Bước 3: Hiển thị ra màn hình bằng wp_nav_menu()

Trong header.php, bạn gọi đúng khóa 'theme_location' => 'primary-menu' để hiển thị chiếc áo đã móc vào:

<?php
wp_nav_menu( array(
    'theme_location' => 'primary-menu',
    'container'      => false,
    'menu_class'     => 'my-nav-bar',
    'fallback_cb'    => false,
) );
?>

VI. Giải thích chi tiết các tham số của hàm wp_nav_menu()

Khi dùng hàm wp_nav_menu( array(...) ), đây là ý nghĩa thực tế của các tùy chọn bạn thường gặp nhất:

Tham số Giá trị khuyên dùng Tại sao lại dùng như vậy?
theme_location 'primary-menu' Bắt buộc phải khớp chính xác với khóa vị trí đã đăng ký trong functions.php.
container false Mặc định WordPress sẽ tự sinh một thẻ <div class="menu-container"> bọc ngoài thẻ <ul>. Đặt false để bỏ thẻ div thừa này, giúp code HTML sạch đẹp và chuẩn CSS hơn.
menu_class 'nav-menu' Tên class CSS gán trực tiếp vào thẻ <ul> để bạn dễ viết CSS Flexbox hoặc Grid.
fallback_cb false Nếu người quản trị chưa vào Admin tạo menu, mặc định WordPress sẽ tự động in ra toàn bộ tất cả các trang làm vỡ giao diện web. Đặt false sẽ ẩn đi cho đến khi menu được tạo.
depth 0 hoặc 1 0: Cho phép hiển thị menu con không giới hạn cấp độ (phù hợp menu header có dropdown).
1: Chỉ hiển thị menu cấp 1 cha (rất phù hợp cho menu footer).

VII. 3 Lỗi phổ biến nhất của người mới và cách xử lý

1. Lỗi: Mất thanh Admin Bar màu đen khi xem ngoài trang chủ

Nguyên nhân: Quên gọi hàm <?php wp_footer(); ?> ở cuối file footer.php.

Cách sửa: Luôn kiểm tra xem ngay trước thẻ đóng </body> đã có <?php wp_footer(); ?> chưa.

2. Lỗi: Menu tự động hiển thị hàng loạt trang lung tung làm vỡ web

Nguyên nhân: Trong code chưa thêm tham số 'fallback_cb' => false, hoặc trong Admin bạn đã tạo menu nhưng quên chưa tích chọn vị trí hiển thị (Display location).

Cách sửa: Vào Giao diện → Menu, kéo xuống dưới cùng mục Vị trí hiển thị và tích chọn đúng tên menu đã tạo.

3. Lỗi: Logo không đổi được trong Customize (Tùy biến)

Nguyên nhân: Theme chưa khai báo tính năng hỗ trợ logo tùy biến custom-logo trong functions.php.

Cách sửa: Kiểm tra trong hàm theme_setup (hook after_setup_theme) của functions.php xem đã có đoạn mã này chưa:

add_theme_support( 'custom-logo', array(
    'height'      => 80,
    'width'       => 240,
    'flex-height' => true,
    'flex-width'  => true,
) );
💡 Mẹo nâng cao: Dùng Header / Footer biến thể cho Landing Page:
Khi muốn tạo trang Landing Page chạy quảng cáo không có Logo và không có Menu điều hướng (tránh khách thoát trang):
  1. Tạo file header-landing.php với giao diện tối giản.
  2. Trong template trang gọi: <?php get_header( 'landing' ); ?>.
  3. WordPress sẽ tự động nạp header-landing.php thay thế cho header.php. Tương tự, gọi get_footer( 'landing' ) để nạp footer-landing.php.
