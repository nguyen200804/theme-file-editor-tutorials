Hướng dẫn tạo Header, Footer và Đăng ký / Gọi Menu trong WordPress Theme

Quy trình chuẩn xây dựng Header & Footer: các hook sống còn của WordPress, cách đăng ký vị trí menu trong functions.php, gán menu trong Admin và hiển thị ra ngoài giao diện.

I. Các Hook bắt buộc phải có trong Header & Footer

Trong theme WordPress, có 3 hàm hook sống còn bắt buộc phải xuất hiện. Nếu thiếu chúng, thanh công cụ Admin Bar sẽ biến mất, các plugin (SEO, Contact Form, Google Analytics) và file CSS/JS sẽ không thể tải được vào trang:

Hàm Hook Vị trí đặt bắt buộc Ý nghĩa & Vai trò
<?php wp_head(); ?> Đặt ngay TRƯỚC thẻ đóng </head> trong header.php. Nạp toàn bộ CSS, font chữ, thẻ meta SEO, favicon và mã script phần đầu trang của theme và plugin.
<?php wp_body_open(); ?> Đặt ngay SAU thẻ mở <body> trong header.php. Kích hoạt hook chuẩn cho các mã theo dõi như Google Tag Manager (GTM), pixel chèn mã noscript.
<?php wp_footer(); ?> Đặt ngay TRƯỚC thẻ đóng </body> trong footer.php. Nạp toàn bộ file JavaScript (JS), thanh công cụ Admin Bar phía trên cùng và các modal/popup.
⚠️ Cảnh báo thường gặp: Khi bạn thấy website bị vỡ giao diện (mất CSS), mất thanh đen Admin Bar khi đã đăng nhập, hoặc bấm nút gửi form không có phản hồi — 99% nguyên nhân là do quên gọi wp_head() hoặc wp_footer()!

II. Quy trình 3 bước Đăng ký & Gọi Menu

Bước 1: Đăng ký vị trí Menu trong functions.php

Mở file functions.php, sử dụng hàm register_nav_menus() móc vào action hook after_setup_theme:

function theme_setup_menus() {
    register_nav_menus( array(
        'primary-menu' => 'Menu Chính (Header)',
        'footer-menu'  => 'Menu Chân Trang (Footer)',
        'mobile-menu'  => 'Menu Di Động (Mobile Drawer)',
    ) );
}
add_action( 'after_setup_theme', 'theme_setup_menus' );

Bước 2: Tạo Menu và Gán vị trí trong WordPress Admin

  1. Truy cập vào Giao diện (Appearance) → Trình đơn (Menus).
  2. Đặt tên menu (VD: "Menu Đầu Trang") và bấm Tạo trình đơn (Create Menu).
  3. Chọn các trang (Trang chủ, Giới thiệu, Sản phẩm, Liên hệ...) ở cột bên trái và bấm Thêm vào trình đơn.
  4. Ở phần Cài đặt trình đơn → Vị trí hiển thị (Display location): Tích chọn vào "Menu Chính (Header)".
  5. Bấm Lưu trình đơn (Save Menu).

Bước 3: Hiển thị Menu ra giao diện bằng wp_nav_menu()

Đặt đoạn code sau vào vị trí bạn muốn menu xuất hiện (trong header.php hoặc footer.php):

<nav class="main-nav" aria-label="Menu chính">
    <?php
    wp_nav_menu( array(
        'theme_location' => 'primary-menu', // Khóa vị trí đã đăng ký ở Bước 1
        'container'      => false,          // Bỏ thẻ div bọc ngoài mặc định
        'menu_class'     => 'nav-list',      // Thêm class CSS cho thẻ <ul>
        'fallback_cb'    => false,          // Không in ra gì nếu Admin chưa gán menu
    ) );
    ?>
</nav>

III. Cấu trúc chuẩn của file header.php

Một file header.php hoàn chỉnh, hỗ trợ Logo tùy biến từ Admin (Custom Logo) và Menu chính điều hướng:

<!DOCTYPE html>
<html <?php language_attributes(); ?>>
<head>
    <meta charset="<?php bloginfo( 'charset' ); ?>">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <?php wp_head(); // BẮT BUỘC: Nạp CSS và mã nguồn header ?>
</head>

<body <?php body_class(); ?>>
<?php wp_body_open(); // BẮT BUỘC: Hỗ trợ mã theo dõi (GTM, Analytics) ?>

<header class="site-header">
    <div class="container header-inner">
        
        <!-- Logo hoặc Tên website -->
        <div class="site-branding">
            <?php if ( has_custom_logo() ) : ?>
                <?php the_custom_logo(); ?>
            <?php else : ?>
                <a class="site-title" href="<?php echo esc_url( home_url( '/' ) ); ?>">
                    <?php bloginfo( 'name' ); ?>
                </a>
            <?php endif; ?>
        </div>

        <!-- Menu điều hướng chính -->
        <nav class="main-navigation" aria-label="Menu chính">
            <?php
            wp_nav_menu( array(
                'theme_location' => 'primary-menu',
                'container'      => false,
                'menu_class'     => 'menu-main',
                'fallback_cb'    => false,
            ) );
            ?>
        </nav>

    </div>
</header>

IV. Cấu trúc chuẩn của file footer.php

File footer.php chứa phần chân trang, menu phụ (chính sách, điều khoản), bản quyền tự động cập nhật năm hiện tại và đóng các thẻ HTML:

<footer class="site-footer">
    <div class="container footer-inner">
        
        <!-- Menu chân trang (Chính sách, Điều khoản...) -->
        <nav class="footer-navigation" aria-label="Menu chân trang">
            <?php
            wp_nav_menu( array(
                'theme_location' => 'footer-menu',
                'container'      => false,
                'menu_class'     => 'menu-footer',
                'depth'          => 1, // Chỉ hiện 1 cấp cha (không xổ submenu)
                'fallback_cb'    => false,
            ) );
            ?>
        </nav>

        <!-- Dòng bản quyền tự cập nhật năm hiện tại -->
        <div class="site-copyright">
            <p>&copy; <?php echo esc_html( date( 'Y' ) ); ?> <?php bloginfo( 'name' ); ?>. All rights reserved.</p>
        </div>

    </div>
</footer>

<?php wp_footer(); // BẮT BUỘC: Nạp JS và thanh công cụ Admin Bar ?>
</body>
</html>

V. Cách gọi Header và Footer trong các Template

Trong mọi file template như page.php, single.php, index.php, bạn luôn kẹp nội dung ở giữa hai hàm sau:

<?php get_header(); // Tự động nạp file header.php ?>

<main class="site-main container">
    <!-- Nội dung trang web nằm ở đây -->
</main>

<?php get_footer(); // Tự động nạp file footer.php ?>

Mẹo nâng cao: Dùng Header / Footer biến thể cho Landing Page

Nếu bạn muốn trang Landing Page chạy quảng cáo có Header tối giản (không logo, không menu điều hướng để tránh khách thoát trang):

  1. Tạo file mới tên là header-landing.php đặt tại thư mục theme.
  2. Trong file template của trang Landing Page, thay vì gọi get_header() mặc định, bạn gọi: 
    <?php get_header( 'landing' ); ?>
  3. WordPress sẽ tự động nạp file header-landing.php thay thế. Tương tự, bạn cũng có thể dùng <?php get_footer( 'landing' ); ?> để nạp footer-landing.php.

VI. Bảng tra cứu các tham số quan trọng trong wp_nav_menu()

Tham số (Key) Giá trị khuyên dùng Ý nghĩa & Cách sử dụng
theme_location 'primary-menu' Tên vị trí định danh menu đã đăng ký trong register_nav_menus().
container false Thẻ bọc ngoài thẻ <ul>. Mặc định là 'div', nên để false để code HTML gọn gàng.
container_class 'menu-wrap' Class CSS gắn cho thẻ bọc ngoài nếu container khác false.
menu_class 'nav-menu flex' Class CSS gắn trực tiếp vào thẻ <ul> của danh sách menu.
fallback_cb false Hàm dự phòng chạy khi Admin chưa tạo menu. Đặt false để không tự in danh sách trang linh tinh.
depth 0 hoặc 1 Độ sâu cấp độ menu (0: cho phép menu đa cấp không giới hạn; 1: chỉ lấy cấp 1 cha).
echo true true: In thẳng ra màn hình; false: Trả về chuỗi HTML để gán biến.
