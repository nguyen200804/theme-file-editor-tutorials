Custom field thay ACF

Bộ khung nhỏ dùng meta box gốc của WordPress: khai báo field bằng mảng, tự động vẽ form, kiểm tra nonce bảo mật, lọc dữ liệu sạch và lưu trữ nhẹ hơn nhiều so với cài plugin ACF.

inc/fields/
├── loader.php        # nạp các file bên dưới
├── core.php          # đăng ký meta box, vẽ input, lưu post meta
├── helpers.php       # hàm lấy dữ liệu: ten_field(), ten_term_field(), ten_option()
├── term-meta.php     # custom field cho Category & Taxonomy
├── options-page.php  # trang cài đặt chung cho website (Theme Options)
└── config/           # mỗi nhóm field một file cấu hình
    ├── san-pham.php
    ├── taxonomy.php
    └── theme-settings.php
assets/js/admin-fields.js   # xử lý chọn ảnh Media Library, gallery, repeater

Mã nguồn đầy đủ của core.php, helpers.php, term-meta.php, options-page.php và admin-fields.js đặt trong thư mục theme-code/ của repo này.

1. Field Group (Nhóm trường dữ liệu)

Field Group là khái niệm cốt lõi dùng để gom các trường dữ liệu liên quan lại thành một nhóm hoàn chỉnh. Một Field Group bao gồm: tên nhóm, vị trí hiển thị và danh sách các trường dữ liệu con.

Đối tượng áp dụng Vị trí xuất hiện trong Admin Bảng lưu trong Database
Post Type (Bài viết, Trang, CPT) Hiển thị dạng hộp Meta Box ở giữa hoặc cột phải trang soạn thảo wp_postmeta
Taxonomy (Category, Tag, Custom Taxonomy) Hiển thị các ô nhập liệu bổ sung trong trang Sửa danh mục wp_termmeta
Option Page (Cài đặt chung toàn website) Hiển thị thành từng khối / section trong trang Theme Settings wp_options

📐 Công thức cấu tạo tổng quát của một Field Group:

ten_add_meta_box( array(
    // 1. Nhận diện nhóm (Bắt buộc)
    'id'         => '{id_nhom_duy_nhat}',         // Chuỗi không dấu, không trùng lặp
    'title'      => '{Tiêu đề hộp hiển thị}',     // Tên nhóm xuất hiện trên giao diện Admin
    
    // 2. Vị trí gán (Location)
    'post_types' => array( '{slug_post_type}' ),  // Áp dụng cho: 'post', 'page', hoặc CPT
    'template'   => '{duong_dan_template}',       // (Tùy chọn) Chỉ hiện khi chọn đúng Page Template
    
    // 3. Vị trí & Thứ tự trên màn hình
    'context'    => 'normal',                     // 'normal' (ở giữa) hoặc 'side' (cột bên phải)
    'priority'   => 'high',                       // 'high' (ưu tiên trên cùng) hoặc 'default'
    
    // 4. Danh sách các trường dữ liệu con (Fields Array)
    'fields'     => array(
        array( 'key' => '{key_1}', 'label' => '{Nhãn 1}', 'type' => '{kieu_field}' ),
        array( 'key' => '{key_2}', 'label' => '{Nhãn 2}', 'type' => '{kieu_field}' ),
    ),
) );

💡 Ví dụ thực tế 1: Field Group lọc theo Page Template Giới thiệu

Nhóm trường chỉ hiển thị khi trang tĩnh chọn template templates/page-about.php:

// inc/fields/config/page-about.php
ten_add_meta_box( array(
    'id'         => 'thong_ke_gioi_thieu',
    'title'      => 'Các con số ấn tượng (Thống kê)',
    'post_types' => array( 'page' ),
    'template'   => 'templates/page-about.php', // Chỉ kích hoạt khi gán đúng Template
    'context'    => 'normal',
    'fields'     => array(
        array( 'key' => 'nam_kinh_nghiem', 'label' => 'Số năm kinh nghiệm',   'type' => 'number' ),
        array( 'key' => 'so_khach_hang',   'label' => 'Khách hàng tin tưởng', 'type' => 'number' ),
        array( 'key' => 'so_du_an',        'label' => 'Dự án đã bàn giao',    'type' => 'number' ),
    ),
) );

// Lấy ra dùng trong templates/page-about.php:
<div class="stats-grid">
    <div class="stat-item"><?php echo esc_html( ten_field( 'nam_kinh_nghiem' ) ); ?>+ Năm</div>
    <div class="stat-item"><?php echo esc_html( ten_field( 'so_khach_hang' ) ); ?>+ Khách hàng</div>
    <div class="stat-item"><?php echo esc_html( ten_field( 'so_du_an' ) ); ?>+ Dự án</div>
</div>

💡 Ví dụ thực tế 2: Field Group hiển thị ở cột bên phải (Side Box)

Nhóm trường nhỏ hiển thị gọn ở cột bên phải màn hình viết bài:

// inc/fields/config/post-extra.php
ten_add_meta_box( array(
    'id'         => 'nguon_bai_viet',
    'title'      => 'Nguồn & Bản quyền bài viết',
    'post_types' => array( 'post' ),
    'context'    => 'side', // Hiển thị ở cột bên phải
    'priority'   => 'default',
    'fields'     => array(
        array( 'key' => 'tac_gia_goc', 'label' => 'Tác giả gốc', 'type' => 'text' ),
        array( 'key' => 'link_nguon',   'label' => 'Link bài viết gốc', 'type' => 'url' ),
    ),
) );

2. Post Type (Áp dụng cho Bài viết & Custom Post Type)

Dùng để thêm các trường dữ liệu riêng biệt cho từng bài viết, trang tĩnh hoặc custom post type (sản phẩm, dự án, dịch vụ...). Dữ liệu lưu vào bảng wp_postmeta.

📐 Công thức:

// 1. Công thức Khai báo (inc/fields/config/{post-type}.php)
ten_add_meta_box( array(
    'id'         => '{id_nhom}',                  // Mã định danh nhóm (duy nhất)
    'title'      => '{Tiêu đề hộp Meta Box}',    // Tên hiển thị trên thanh tiêu đề
    'post_types' => array( '{slug_post_type}' ),  // Áp dụng cho: 'post', 'page', hoặc CPT
    'context'    => 'normal',                     // Vị trí: 'normal' (chính giữa) hoặc 'side' (cột phải)
    'fields'     => array(
        array( 'key' => '{key_1}', 'label' => '{Nhãn 1}', 'type' => '{kieu_field}' ),
        array( 'key' => '{key_2}', 'label' => '{Nhãn 2}', 'type' => '{kieu_field}' ),
    ),
) );

// 2. Công thức Lấy dữ liệu (trong single-{post_type}.php hoặc loop/card.php)
<?php echo esc_html( ten_field( '{key_1}' ) ); ?>

💡 Ví dụ thực tế: Thêm thông tin cho Post Type Sản phẩm

// Khai báo trong inc/fields/config/san-pham.php
ten_add_meta_box( array(
    'id'         => 'thong-tin-san-pham',
    'title'      => 'Thông tin sản phẩm',
    'post_types' => array( 'san-pham' ),
    'context'    => 'normal',
    'fields'     => array(
        array( 'key' => 'gia',       'label' => 'Giá bán (đ)',       'type' => 'number' ),
        array( 'key' => 'bao_hanh',  'label' => 'Thời gian bảo hành', 'type' => 'text' ),
        array( 'key' => 'album_anh', 'label' => 'Album ảnh chi tiết', 'type' => 'gallery' ),
    ),
) );

// Lấy ra hiển thị trong single-san-pham.php:
<div class="product-info">
    <p>Giá: <strong><?php echo esc_html( number_format_i18n( ten_field( 'gia' ) ) ); ?> đ</strong></p>
    <p>Bảo hành: <?php echo esc_html( ten_field( 'bao_hanh' ) ); ?></p>
    <div class="gallery">
        <?php echo ten_gallery( 'album_anh' ); ?>
    </div>
</div>

3. Taxonomy (Áp dụng cho Chuyên mục & Phân loại)

Dùng để bổ sung thêm các trường tùy biến vào trang Thêm / Sửa Danh mục (như banner, icon, màu sắc). Dữ liệu lưu vào bảng wp_termmeta.

📐 Công thức:

// 1. Công thức Khai báo (inc/fields/config/taxonomy.php)
ten_add_term_fields( array(
    'taxonomy' => '{slug_taxonomy}', // Áp dụng cho: 'category', 'post_tag', hoặc custom taxonomy
    'fields'   => array(
        array( 'key' => '{key_1}', 'label' => '{Nhãn 1}', 'type' => '{kieu_field}' ),
    ),
) );

// 2. Công thức Lấy dữ liệu (trong category.php, taxonomy.php hoặc archive.php)
<?php
$term_id = get_queried_object_id(); // Lấy ID của term đang xem
echo esc_html( ten_term_field( $term_id, '{key_1}' ) );
?>

💡 Ví dụ thực tế: Thêm Banner & Mã màu cho Loại sản phẩm

// Khai báo trong inc/fields/config/taxonomy.php
ten_add_term_fields( array(
    'taxonomy' => 'loai-san-pham',
    'fields'   => array(
        array( 'key' => 'anh_banner', 'label' => 'Ảnh Banner đầu trang', 'type' => 'image' ),
        array( 'key' => 'mau_chu_dao', 'label' => 'Mã màu chủ đạo (#hex)', 'type' => 'text' ),
    ),
) );

// Lấy ra hiển thị trong taxonomy-loai-san-pham.php:
<?php
$term_id   = get_queried_object_id();
$banner_id = ten_term_field( $term_id, 'anh_banner' );
$color     = ten_term_field( $term_id, 'mau_chu_dao' );
?>
<header class="tax-header" style="background-color: <?php echo esc_attr( $color ); ?>;">
    <?php if ( $banner_id ) : ?>
        <?php echo wp_get_attachment_image( $banner_id, 'full', false, array( 'class' => 'tax-banner' ) ); ?>
    <?php endif; ?>
    <h1><?php single_term_title(); ?></h1>
</header>

4. Option Page (Trang cài đặt chung toàn site - Theme Settings)

Dùng để tạo một trang quản trị tập trung lưu các cấu hình dùng chung toàn site (Logo, Hotline, Email, Bản quyền, Mã Google Analytics...). Dữ liệu lưu vào bảng wp_options.

📐 Công thức:

// 1. Công thức Khai báo (inc/fields/config/theme-settings.php)
ten_add_options_page( array(
    'page_title' => '{Tiêu đề trang}',       // Tiêu đề trang quản trị
    'menu_title' => '{Tên menu}',            // Tên hiển thị trên menu Admin
    'menu_slug'  => '{slug_trang_cai_dat}',   // Slug URL trong admin
    'icon'       => 'dashicons-admin-generic', // Icon dashicon
    'fields'     => array(
        array( 'key' => '{key_1}', 'label' => '{Nhãn 1}', 'type' => '{kieu_field}' ),
    ),
) );

// 2. Công thức Lấy dữ liệu (ở bất kỳ file nào: header.php, footer.php...)
<?php echo esc_html( ten_option( '{key_1}' ) ); ?>

💡 Ví dụ thực tế: Cài đặt Hotline, Email và Bản quyền Footer

// Khai báo trong inc/fields/config/theme-settings.php
ten_add_options_page( array(
    'page_title' => 'Cài đặt chung Website',
    'menu_title' => 'Cài đặt Theme',
    'menu_slug'  => 'theme-settings',
    'icon'       => 'dashicons-admin-generic',
    'fields'     => array(
        array( 'key' => 'hotline',     'label' => 'Số Hotline',      'type' => 'text' ),
        array( 'key' => 'email',       'label' => 'Email liên hệ',   'type' => 'email' ),
        array( 'key' => 'footer_copy', 'label' => 'Bản quyền Footer','type' => 'text' ),
    ),
) );

// Lấy ra trong header.php (Hotline):
<a href="tel:<?php echo esc_attr( ten_option( 'hotline' ) ); ?>" class="header-hotline">
    Hotline: <?php echo esc_html( ten_option( 'hotline' ) ); ?>
</a>

// Lấy ra trong footer.php (Bản quyền):
<footer class="site-footer">
    <p>&copy; <?php echo date('Y'); ?> <?php echo esc_html( ten_option( 'footer_copy' ) ); ?></p>
</footer>

5. Các kiểu trường hỗ trợ & cách lấy dữ liệu

type Kiểu dữ liệu lưu Hàm lấy trong Template
text, date, number, select Chuỗi / số ten_field('key')
url, email Chuỗi định dạng esc_url( ten_field('key') )
textarea Đoạn văn bản nhiều dòng nl2br( esc_html( ten_field('key') ) )
checkbox '1' hoặc '0' '1' === ten_field('key')
image ID file ảnh trong Media ten_image('key', 'size')
gallery Mảng danh sách các ID ảnh ten_gallery('key')
repeater Mảng dữ liệu nhiều hàng foreach ( ten_field('key') as $row )

6. Nguyên tắc an toàn & tối ưu

  • Đặt key rõ ràng: Đặt key chữ thường không dấu, dùng dấu gạch dưới (VD: gia_khuyen_mai). Tuyệt đối không đổi key sau khi đã nhập nội dung nếu không muốn dữ liệu cũ bị ẩn.
  • Escape dữ liệu: Luôn lọc dữ liệu trước khi xuất ra HTML: esc_html() cho chữ, esc_url() cho liên kết, esc_attr() cho thuộc tính thẻ.
  • Không lồng Repeater: Bộ khung thuần được thiết kế tinh gọn để tối ưu tốc độ, do đó repeater chỉ chứa các sub-field đơn, không lồng repeater bên trong repeater.
