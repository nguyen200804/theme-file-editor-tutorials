Tạo Template Archive (Trang danh sách)

Template Archive dùng để hiển thị danh sách bài viết theo chuyên mục (Category), thẻ (Tag), tác giả (Author) hoặc danh sách của Custom Post Type (Sản phẩm, Dự án, Tin tức...).

1. Các loại file Template Archive

Loại danh sách Tên file (hoặc đặt trong archive/) Điều kiện & Ghi chú
Archive chung archive.php Dự phòng cuối cùng cho tất cả danh sách nếu không có file chuyên biệt.
Custom Post Type archive-{post_type}.php
Ví dụ: archive-san-pham.php		 Khi đăng ký post type trong register_post_type(), bắt buộc phải có thuộc tính 'has_archive' => true.
Chuyên mục (Category) category-{slug}.php
category.php		 Áp dụng cho danh mục bài viết mặc định.
Custom Taxonomy taxonomy-{tax}-{term}.php
taxonomy-{tax}.php
Ví dụ: taxonomy-loai-san-pham.php		 Áp dụng cho các nhóm phân loại tùy biến của Custom Post Type.
Thẻ (Tag) / Tác giả (Author) tag.php, author.php, date.php Hiển thị bài viết theo tag, tác giả hoặc mốc thời gian.

2. Cấu trúc chuẩn của một file Archive

Code mẫu file archive-san-pham.php (hoặc archive/archive-san-pham.php nếu dùng loader):

<?php
/**
 * Template Archive cho Custom Post Type "san-pham"
 * Đường dẫn URL: domain.com/san-pham/
 */

get_header(); ?>

<main id="primary" class="site-main archive-container container">

    <!-- 1. Tiêu đề và mô tả của Archive -->
    <header class="archive-header">
        <h1 class="archive-title">
            <?php
            if ( is_post_type_archive() ) {
                post_type_archive_title();
            } else {
                the_archive_title();
            }
            ?>
        </h1>
        <?php
        // In mô tả của taxonomy / category nếu có
        the_archive_description( '<div class="archive-description lead">', '</div>' );
        ?>
    </header>

    <!-- 2. Vòng lặp danh sách sản phẩm / bài viết -->
    <?php if ( have_posts() ) : ?>

        <div class="product-grid">
            <?php
            while ( have_posts() ) :
                the_post();
                // Nạp card item tương ứng từ template-parts/loop/
                get_template_part( 'template-parts/loop/card', get_post_type() );
            endwhile;
            ?>
        </div>

        <!-- 3. Phân trang chuẩn WordPress -->
        <nav class="pagination-wrap" aria-label="Phân trang">
            <?php
            the_posts_pagination( array(
                'mid_size'  => 2,
                'prev_text' => '« Trang trước',
                'next_text' => 'Trang sau »',
            ) );
            ?>
        </nav>

    <?php else : ?>

        <!-- Khi danh sách không có bài viết nào -->
        <?php get_template_part( 'template-parts/loop/none' ); ?>

    <?php endif; ?>

</main>

<?php get_footer(); ?>

3. Bóc tách Card Item trong template-parts/loop/

Để code gọn và tái sử dụng được ở nhiều trang khác (như trang chủ hay widget), ta tạo file template-parts/loop/card-san-pham.php:

<article id="post-<?php the_ID(); ?>" <?php post_class( 'product-card' ); ?>>
    <a href="<?php the_permalink(); ?>" class="product-thumb">
        <?php if ( has_post_thumbnail() ) : ?>
            <?php the_post_thumbnail( 'medium' ); ?>
        <?php else : ?>
            <img src="<?php echo esc_url( get_template_directory_uri() . '/assets/images/no-thumb.png' ); ?>" alt="<?php the_title_attribute(); ?>">
        <?php endif; ?>
    </a>

    <div class="product-body">
        <h3 class="product-name">
            <a href="<?php the_permalink(); ?>"><?php the_title(); ?></a>
        </h3>
        <div class="product-price">
            <?php echo esc_html( number_format_i18n( ten_field( 'gia' ) ) ); ?> đ
        </div>
    </div>
</article>

4. Cách chỉnh số bài và sắp xếp qua pre_get_posts

LƯU Ý CỰC KỲ QUAN TRỌNG:
Tuyệt đối không dùng query_posts() hoặc tạo new WP_Query() để ghi đè vòng lặp chính trong template archive. Việc đó sẽ làm hỏng phân trang (lỗi 404 trang 2, 3...) và khiến database phải truy vấn 2 lần.

Cách chuẩn mực nhất là dùng hook pre_get_posts trong functions.php:

// functions.php
function ten_theme_customize_archive( $query ) {
    // Chỉ can thiệp ở ngoài frontend và là truy vấn chính (Main Query)
    if ( ! is_admin() && $query->is_main_query() ) {

        // Tùy biến riêng cho archive sản phẩm và taxonomy loại sản phẩm
        if ( is_post_type_archive( 'san-pham' ) || is_tax( 'loai-san-pham' ) ) {
            $query->set( 'posts_per_page', 12 ); // 12 sản phẩm mỗi trang
            $query->set( 'orderby', 'date' );
            $query->set( 'order', 'DESC' );
        }

        // Tùy biến cho category tin tức
        if ( is_category() ) {
            $query->set( 'posts_per_page', 8 );
        }
    }
}
add_action( 'pre_get_posts', 'ten_theme_customize_archive' );

5. Bỏ tiền tố mặc định của the_archive_title()

Mặc định WordPress sẽ hiển thị các tiền tố như "Chuyên mục: ", "Thẻ: ", "Lưu trữ: ". Để xóa bỏ tiền tố này cho tiêu đề gọn gàng, thêm bộ lọc sau vào functions.php:

add_filter( 'get_the_archive_title_prefix', '__return_empty_string' );
