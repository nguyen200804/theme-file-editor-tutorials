Hướng dẫn cấu hình theme WordPress

Cách tổ chức file trong Theme File Editor: template cho trang, bài viết, danh sách, phần dùng lại và custom field tự viết thay ACF.

Bắt đầu

Theme chỉ cần 2 file: style.css và index.php. Mọi file khác thêm khi cần.

  1. Tạo file bằng FTP hoặc cPanel File Manager. Theme File Editor không có nút tạo file mới.
  2. Sửa nội dung trong Appearance → Theme File Editor.
  3. Làm trong child theme và sao lưu trước khi sửa. Một lỗi cú pháp PHP có thể làm sập site.
Block theme (Twenty Twenty-Four...) không có Theme File Editor và dùng templates/*.html. Hướng dẫn này dành cho classic theme.

Tên {key} trong single-{key}.php hoặc taxonomy-{key}.php là key trong register_post_type() / register_taxonomy(), không phải label hiển thị.

Thứ tự chọn template

WordPress đi từ cụ thể đến chung, gặp file nào tồn tại thì dùng và dừng.

Loại Thứ tự (cao → thấp)
Trang tĩnh Template chọn tay → page-{slug} → page-{id} → page → singular → index
Trang chủ front-page → (home hoặc page) → index
Bài viết single-post-{slug} → single-post → single → singular → index
Custom post type single-{pt}-{slug} → single-{pt} → single → singular → index
Category category-{slug} → category-{id} → category → archive → index
Tag tag-{slug} → tag-{id} → tag → archive → index
Custom taxonomy taxonomy-{tax}-{term} → taxonomy-{tax} → taxonomy → archive → index
Archive post type archive-{pt} → archive → index (cần has_archive)
Tác giả author-{nicename} → author-{id} → author → archive → index

singular.php là lưới an toàn của cả single.php và page.php: nó chỉ được dùng cho loại nội dung nào mà file chuyên biệt của nó không tồn tại. front-page.php luôn được dùng cho trang chủ, bất kể cài đặt trong Settings → Reading.

Gom file vào folder

WordPress không tự tìm template trong thư mục con. Thêm file inc/template-loader.php để nó tìm trong page/, single/, archive/ trước, rồi mới tới thư mục gốc:

<?php
$template_folders = array(
    'frontpage' => 'page',    'home'     => 'page',
    'page'      => 'page',    'single'   => 'single',
    'singular'  => 'single',  'attachment' => 'single',
    'archive'   => 'archive', 'category' => 'archive',
    'tag'       => 'archive', 'taxonomy' => 'archive',
    'author'    => 'archive', 'date'     => 'archive',
);

foreach ( $template_folders as $type => $folder ) {
    add_filter( "{$type}_template_hierarchy", function ( $templates ) use ( $folder ) {
        $result = array();
        foreach ( $templates as $template ) {
            if ( false === strpos( $template, '/' ) ) {
                $result[] = $folder . '/' . $template;
            }
            $result[] = $template;
        }
        return $result;
    } );
}

Nạp trong functions.php:

require_once get_stylesheet_directory() . '/inc/template-loader.php';

Page Template có Template Name: đặt trong templates/. WordPress chỉ quét một cấp thư mục con cho loại này.

Template parts

Folder Là gì Ví dụ
section/ Khối lớn của trang hero, faq, cta
loop/ Một mục trong danh sách; none.php chạy khi danh sách rỗng card, list-item, none
content/ Thân nội dung single/page content-san-pham
ui/ Mảnh nhỏ dùng nhiều nơi button, badge, breadcrumb
layout/ Mảnh của header/footer nav-main
form/ Biểu mẫu search, newsletter

Quy tắc ghép: section gọi loop, loop gọi ui. Không cần loader, vì get_template_part() tự tìm theo đường dẫn.

get_template_part( 'template-parts/section/hero' );
get_template_part( 'template-parts/loop/card', get_post_type() );
get_template_part( 'template-parts/ui/button', null, array(
    'text' => 'Liên hệ', 'url' => home_url( '/lien-he/' ),
) ); // nhận qua $args (WordPress 5.5+)
<?php if ( have_posts() ) :
    while ( have_posts() ) : the_post();
        get_template_part( 'template-parts/loop/card', get_post_type() );
    endwhile;
    the_posts_pagination();
else :
    get_template_part( 'template-parts/loop/none' );
endif;

Custom field thay ACF

Bộ khung nhỏ dùng meta box gốc: khai báo field bằng mảng, khung tự vẽ form, kiểm tra nonce, làm sạch và lưu dữ liệu.

inc/fields/
├── loader.php      # nạp các file bên dưới
├── core.php        # đăng ký meta box, vẽ field, lưu
├── helpers.php     # ten_field(), ten_image(), ten_gallery()
├── term-meta.php   # field cho category / taxonomy
└── config/         # mỗi nhóm field một file
    └── san-pham.php
assets/js/admin-fields.js   # chọn ảnh, gallery, repeater

Mã nguồn đầy đủ của core.php, helpers.php, term-meta.php và admin-fields.js đặt trong thư mục theme-code/ của repo này.

Khai báo field

<?php
ten_add_meta_box( array(
    'id'         => 'thong-tin-san-pham',
    'title'      => 'Thông tin sản phẩm',
    'post_types' => array( 'san-pham' ),
    'fields'     => array(
        array( 'key' => 'gia',    'label' => 'Giá (đ)', 'type' => 'number' ),
        array( 'key' => 'noi_bat','label' => 'Nổi bật',  'type' => 'checkbox' ),
        array( 'key' => 'anh',    'label' => 'Ảnh',      'type' => 'image' ),
        array( 'key' => 'thong_so','label' => 'Thông số', 'type' => 'repeater',
            'sub_fields' => array(
                array( 'key' => 'ten',     'label' => 'Tên',     'type' => 'text' ),
                array( 'key' => 'gia_tri', 'label' => 'Giá trị', 'type' => 'text' ),
            ) ),
    ),
) );

Dùng trong template

<?php echo esc_html( number_format_i18n( ten_field( 'gia' ) ) ); ?> đ
<?php echo ten_image( 'anh', 'large' ); ?>
<?php foreach ( (array) ten_field( 'thong_so' ) as $row ) : ?>
    <?php echo esc_html( $row['ten'] . ': ' . $row['gia_tri'] ); ?>
<?php endforeach; ?>
type Lưu Lấy ra
text, date, number, select Chuỗi / số ten_field('key')
url, email Chuỗi đã lọc esc_url( ten_field('key') )
textarea Nhiều dòng nl2br( esc_html( ... ) )
checkbox '1' hoặc '0' '1' === ten_field('key')
image ID ảnh ten_image('key','size')
gallery Mảng ID ten_gallery('key')
repeater Mảng các dòng foreach ( ten_field('key') ... )
  • Đặt key không dấu, không khoảng trắng. Đổi key sau khi đã nhập dữ liệu thì dữ liệu cũ không hiện nữa.
  • Luôn escape khi in ra: esc_html(), esc_url(), esc_attr().
  • Repeater không lồng được repeater.

Xử lý sự cố

Template mới không chạy

Kiểm tra tên file khớp key (không phải label), đã nạp template-loader.php chưa, rồi vào Settings → Permalinks → Save Changes. Xóa cache nếu có plugin cache.

Không biết trang đang dùng file nào

Cài plugin Query Monitor và xem mục Template: nó liệt kê cả danh sách file ứng viên WordPress đã thử.

Page Template không xuất hiện trong danh sách chọn

Kiểm tra comment Template Name: ở đầu file, file nằm trong thư mục gốc hoặc templates/. Nếu vẫn không thấy, đổi sang theme khác rồi đổi lại để làm mới danh sách.

Site trắng sau khi sửa functions.php

Lỗi cú pháp PHP. Sửa lại file qua FTP hoặc cPanel File Manager, hoặc khôi phục bản sao lưu.
