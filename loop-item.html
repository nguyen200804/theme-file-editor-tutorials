Tạo Loop Item (Thẻ hiển thị bài viết & Taxonomy)

Loop Item (thường gọi là Card / Thẻ item) là mảnh giao diện đại diện cho 1 bài viết hoặc 1 danh mục trong danh sách. Được lưu trong thư mục template-parts/loop/ để tái sử dụng ở bất kỳ trang nào.

template-parts/loop/
├── card.php             # Thẻ bài viết tin tức (post) mặc định
├── card-du-an.php       # Thẻ riêng cho Post Type "du-an"
├── card-san-pham.php    # Thẻ riêng cho Post Type "san-pham"
├── term-card.php        # Thẻ hiển thị một danh mục (Category / Taxonomy)
└── none.php             # Khối thông báo khi danh sách trống

1. Loop Item cho Bài viết & Custom Post Type

Mỗi thẻ bài viết nên bọc trong thẻ <article> cùng hàm post_class() để WordPress tự sinh các class CSS phục vụ tùy biến giao diện.

Code mẫu: template-parts/loop/card-du-an.php

<!-- template-parts/loop/card-du-an.php -->
<article id="post-<?php the_ID(); ?>" <?php post_class( 'project-card' ); ?>>

    <!-- 1. Ảnh đại diện kèm link -->
    <a href="<?php the_permalink(); ?>" class="project-thumb">
        <?php if ( has_post_thumbnail() ) : ?>
            <?php the_post_thumbnail( 'medium', array( 'alt' => the_title_attribute( 'echo=0' ) ) ); ?>
        <?php else : ?>
            <img src="<?php echo esc_url( get_theme_file_uri( 'assets/images/placeholder.jpg' ) ); ?>" alt="No image">
        <?php endif; ?>

        <!-- Badge hiển thị danh mục / loại dự án -->
        <?php
        $terms = get_the_terms( get_the_ID(), 'loai-du-an' );
        if ( ! empty( $terms ) && ! is_wp_error( $terms ) ) : ?>
            <span class="project-badge"><?php echo esc_html( $terms[0]->name ); ?></span>
        <?php endif; ?>
    </a>

    <!-- 2. Nội dung thông tin thẻ -->
    <div class="project-body">
        <h3 class="project-title">
            <a href="<?php the_permalink(); ?>"><?php the_title(); ?></a>
        </h3>

        <!-- Custom field thông tin thêm (ACF / Code thuần) -->
        <div class="project-meta">
            <?php if ( ten_field( 'dia_diem' ) ) : ?>
                <span class="location">📍 <?php echo esc_html( ten_field( 'dia_diem' ) ); ?></span>
            <?php endif; ?>

            <?php if ( ten_field( 'nam_hoan_thanh' ) ) : ?>
                <span class="year">🗓 <?php echo esc_html( ten_field( 'nam_hoan_thanh' ) ); ?></span>
            <?php endif; ?>
        </div>

        <div class="project-excerpt">
            <?php the_excerpt(); ?>
        </div>
    </div>

</article>

2. Loop Item cho Taxonomy (Hiển thị thẻ Danh mục)

Khi bạn cần in ra danh sách các Danh mục / Loại sản phẩm / Chuyên mục nổi bật (ví dụ: lưới các danh mục trên Trang chủ), mỗi danh mục sẽ là 1 Term Card.

Code mẫu: template-parts/loop/term-card.php

<!-- template-parts/loop/term-card.php -->
<?php
// Dữ liệu Term được truyền qua mảng $args trong get_template_part
$term = $args['term'] ?? null;
if ( ! $term ) return;

$term_link = get_term_link( $term );
$banner_id = ten_term_field( $term->term_id, 'anh_banner' );
?>

<div class="term-card">
    <a href="<?php echo esc_url( $term_link ); ?>" class="term-thumb">
        <?php if ( $banner_id ) : ?>
            <?php echo wp_get_attachment_image( $banner_id, 'medium' ); ?>
        <?php else : ?>
            <img src="<?php echo esc_url( get_theme_file_uri( 'assets/images/default-cat.jpg' ) ); ?>" alt="Category">
        <?php endif; ?>
    </a>

    <div class="term-info">
        <h3 class="term-name">
            <a href="<?php echo esc_url( $term_link ); ?>"><?php echo esc_html( $term->name ); ?></a>
        </h3>
        <span class="term-count"><?php echo esc_html( $term->count ); ?> bài viết</span>
    </div>
</div>

3. Khối thông báo danh sách trống (none.php)

Khi chuyên mục hoặc kết quả tìm kiếm không có bài viết nào, hãy nạp file này:

<!-- template-parts/loop/none.php -->
<div class="no-results text-center">
    <h3>Không tìm thấy nội dung</h3>
    <p class="lead">Hiện tại chưa có bài viết nào trong mục này. Vui lòng quay lại sau!</p>
    <a href="<?php echo esc_url( home_url( '/' ) ); ?>" class="btn btn-primary">Về Trang chủ</a>
</div>

4. Cách gọi Loop Item trong các Template

Trường hợp 1: Gọi trong trang Danh sách chính (Archive / Taxonomy)

Tự động nhận diện Post Type hiện tại để nạp đúng file (VD: ở trang archive dự án sẽ tự nạp card-du-an.php):

<?php if ( have_posts() ) : ?>
    <div class="grid-layout">
        <?php
        while ( have_posts() ) : the_post();
            // Tự động tìm card-{post_type}.php, nếu không có sẽ nạp card.php
            get_template_part( 'template-parts/loop/card', get_post_type() );
        endwhile;
        ?>
    </div>
    <?php the_posts_pagination(); ?>
<?php else : ?>
    <?php get_template_part( 'template-parts/loop/none' ); ?>
<?php endif; ?>

Trường hợp 2: Gọi trong truy vấn phụ WP_Query (Trang chủ / Widget)

<?php
$project_query = new WP_Query( array(
    'post_type'      => 'du-an',
    'posts_per_page' => 6,
) );

if ( $project_query->have_posts() ) : ?>
    <div class="project-grid">
        <?php
        while ( $project_query->have_posts() ) : $project_query->the_post();
            get_template_part( 'template-parts/loop/card', 'du-an' );
        endwhile;
        wp_reset_postdata(); // Luôn reset sau truy vấn phụ
        ?>
    </div>
<?php endif; ?>

Trường hợp 3: Xuất danh sách Danh mục / Phân loại (Taxonomy Terms)

<?php
// Lấy danh sách các Loại dự án có chứa bài viết
$terms = get_terms( array(
    'taxonomy'   => 'loai-du-an',
    'hide_empty' => true,
) );

if ( ! empty( $terms ) && ! is_wp_error( $terms ) ) : ?>
    <div class="category-grid">
        <?php foreach ( $terms as $term ) : ?>
            <?php
            // Truyền đối tượng $term sang cho file template-parts/loop/term-card.php
            get_template_part( 'template-parts/loop/term-card', null, array( 'term' => $term ) );
            ?>
        <?php endforeach; ?>
    </div>
<?php endif; ?>
