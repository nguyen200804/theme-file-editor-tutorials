Tra cứu hàm lấy dữ liệu bài viết

Bảng tổng hợp nhanh các hàm chuẩn WordPress để lấy thông tin bài viết (Post / CPT): ảnh đại diện, chuyên mục, ngày giờ, trích dẫn, nội dung và trường dữ liệu tùy biến (Custom Field).

Quy tắc vàng phân biệt giữa the_* và get_the_*:
  • Hàm bắt đầu bằng the_...: Tự động in (echo) thẳng dữ liệu ra màn hình HTML (VD: <?php the_title(); ?>).
  • Hàm bắt đầu bằng get_the_...: Trả về giá trị chuỗi/mảng để gán vào biến hoặc kiểm tra điều kiện if (VD: $title = get_the_title();).

Bảng tra cứu nhanh

Dữ liệu cần lấy In trực tiếp (Echo) Lấy giá trị (Return)
Link bài viết (Post URL) the_permalink() get_permalink()
Tiêu đề bài viết the_title() get_the_title()
Ảnh đại diện (Featured Image) the_post_thumbnail('size') get_the_post_thumbnail_url($id, 'size')
Chuyên mục / Taxonomy Term the_terms($id, 'tax', '', ', ') get_the_terms($id, 'taxonomy')
Ngày đăng bài (Date) echo get_the_date('d/m/Y') get_the_date('d/m/Y')
Giờ đăng bài (Time) echo get_the_time('H:i') get_the_time('H:i')
Trích dẫn ngắn (Excerpt) the_excerpt() get_the_excerpt()
Nội dung chi tiết (Content / Desc) the_content() get_the_content()
ID bài viết hiện tại the_ID() get_the_ID()
Custom Field (Code thuần) echo esc_html(ten_field('key')) ten_field('key')
Custom Field (WordPress Native) echo get_post_meta($id, 'key', true) get_post_meta($id, 'key', true)
Số lượng bình luận comments_number('0', '1', '%') get_comments_number()
Tên người bình luận comment_author() get_comment_author()
Ảnh đại diện bình luận (Avatar) echo get_avatar($comment, 48) get_avatar_url($comment)
Ngày & Giờ bình luận comment_date('d/m/Y') get_comment_date() / get_comment_time()
Nội dung bình luận comment_text() get_comment_text()
Nút trả lời (Reply link) comment_reply_link(...) get_comment_reply_link(...)

1. Lấy Post URL (Đường dẫn bài viết)

Dùng để gắn link vào tiêu đề hoặc nút "Xem chi tiết".

<!-- Cách 1: In trực tiếp -->
<a href="<?php the_permalink(); ?>"><?php the_title(); ?></a>

<!-- Cách 2: Lấy URL gán vào biến để xử lý logic -->
<?php
$post_url = get_permalink();
echo '<a href="' . esc_url( $post_url ) . '" class="btn-more">Xem chi tiết</a>';
?>

2. Lấy Featured Image (Ảnh đại diện)

Cách 1: In thẻ <img> hoàn chỉnh tự động chuẩn responsive

<?php if ( has_post_thumbnail() ) : ?>
    <a href="<?php the_permalink(); ?>" class="post-thumb">
        <?php the_post_thumbnail( 'medium', array( 'alt' => the_title_attribute( 'echo=0' ) ) ); ?>
    </a>
<?php else : ?>
    <!-- Ảnh mặc định khi bài viết chưa có ảnh đại diện -->
    <img src="<?php echo esc_url( get_theme_file_uri( 'assets/images/no-image.jpg' ) ); ?>" alt="No image">
<?php endif; ?>

Cách 2: Lấy riêng chuỗi URL của ảnh (Làm Background CSS hoặc Slider)

<?php
// Lấy URL ảnh với kích thước tùy chọn: 'thumbnail', 'medium', 'large', 'full'
$thumb_url = get_the_post_thumbnail_url( get_the_ID(), 'full' );
?>
<div class="banner-hero" style="background-image: url('<?php echo esc_url( $thumb_url ); ?>');">
    <h1><?php the_title(); ?></h1>
</div>

3. Lấy Term của Post-Type (Danh mục / Phân loại)

Trường hợp 1: Lấy Term đầu tiên để làm Badge (Nhãn danh mục)

<?php
// Lấy danh sách term của taxonomy 'loai-du-an' (hoặc 'category')
$terms = get_the_terms( get_the_ID(), 'loai-du-an' );

if ( ! empty( $terms ) && ! is_wp_error( $terms ) ) :
    $first_term = $terms[0]; // Lấy danh mục đầu tiên
    $term_link  = get_term_link( $first_term );
    ?>
    <a href="<?php echo esc_url( $term_link ); ?>" class="badge-category">
        <?php echo esc_html( $first_term->name ); ?>
    </a>
<?php endif; ?>

Trường hợp 2: Lặp in toàn bộ các Term có ngăn cách bằng dấu phẩy

<!-- Cách nhanh dùng the_terms -->
<div class="post-tags">
    <?php the_terms( get_the_ID(), 'loai-du-an', 'Chuyên mục: ', ', ', '' ); ?>
</div>

4. Lấy Date & Time (Ngày và Giờ đăng)

Lưu ý: Luôn dùng get_the_date() thay vì the_date(). Vì hàm the_date() mặc định sẽ bị ẩn nếu có 2 bài viết được đăng trong cùng một ngày! 
<!-- Lấy ngày theo định dạng Việt Nam ngày/tháng/năm -->
<span class="post-date">
    📅 <?php echo esc_html( get_the_date( 'd/m/Y' ) ); ?>
</span>

<!-- Lấy giờ đăng bài (24 giờ: 14:30) -->
<span class="post-time">
    ⏰ <?php echo esc_html( get_the_time( 'H:i' ) ); ?>
</span>

<!-- Lấy thời gian tương đối ("cách đây 2 giờ", "3 ngày trước") -->
<span class="time-ago">
    <?php echo esc_html( human_time_diff( get_the_time( 'U' ), current_time( 'timestamp' ) ) . ' trước' ); ?>
</span>

5. Lấy Excerpt (Mô tả ngắn / Trích dẫn)

<!-- Cách 1: In trực tiếp đoạn trích chuẩn (đã lọc thẻ HTML) -->
<div class="post-excerpt">
    <?php the_excerpt(); ?>
</div>

<!-- Cách 2: Cắt ngắn chính xác số lượng từ mong muốn (Ví dụ: đúng 20 từ) -->
<p class="custom-excerpt">
    <?php echo esc_html( wp_trim_words( get_the_excerpt(), 20, '...' ) ); ?>
</p>

6. Lấy Desc / Content (Nội dung chi tiết bài viết)

<!-- Trong file single.php hoặc single-{post_type}.php -->
<div class="entry-content">
    <?php
    // In nội dung đầy đủ (tự động chạy Shortcode, oEmbed video Youtube, khối Gutenberg)
    the_content();
    ?>
</div>

7. Lấy trường dữ liệu Custom Field

Cách 1: Dùng hàm helper của bộ khung Theme (`ten_field`)

<!-- 1. Lấy trường văn bản / số -->
<span class="price">
    Giá: <?php echo esc_html( number_format_i18n( ten_field( 'gia' ) ) ); ?> đ
</span>

<!-- 2. Lấy ảnh custom field -->
<?php echo ten_image( 'anh_so_do', 'large' ); ?>

<!-- 3. Lặp qua danh sách Repeater -->
<ul class="features">
    <?php foreach ( (array) ten_field( 'dac_diem_noi_bat' ) as $row ) : ?>
        <li><?php echo esc_html( $row['ten_dac_diem'] ); ?></li>
    <?php endforeach; ?>
</ul>

Cách 2: Dùng hàm gốc WordPress (`get_post_meta`)

<?php
// get_post_meta( $post_id, $key, $single = true )
$dia_diem = get_post_meta( get_the_ID(), 'dia_diem', true );
if ( ! empty( $dia_diem ) ) {
    echo '<p class="location">Địa điểm: ' . esc_html( $dia_diem ) . '</p>;';
}
?>

8. Tra cứu dữ liệu Bình luận (Comments)

Hệ thống các hàm lấy dữ liệu bình luận của bài viết trong WordPress, từ hiển thị số lượng, danh sách thẻ bình luận đến form gửi phản hồi.

1. Lấy số lượng bình luận

<!-- Cách 1: In trực tiếp kèm chuỗi phân biệt số ít / số nhiều -->
<span class="comment-count">
    💬 <?php comments_number( 'Chưa có bình luận', '1 bình luận', '% bình luận' ); ?>
</span>

<!-- Cách 2: Lấy số lượng nguyên để kiểm tra điều kiện if -->
<?php
$cmt_count = get_comments_number();
if ( $cmt_count > 0 ) {
    echo '<span class="badge">' . esc_html( $cmt_count ) . ' phản hồi</span>';
}
?>

2. Lấy danh sách bình luận (Comment List)

Trong file comments.php, dùng hàm wp_list_comments() để tự động in danh sách bình luận theo cấu trúc phân cấp (lồng nhau khi trả lời):

<ol class="comment-list">
    <?php
    wp_list_comments( array(
        'style'       => 'ol',
        'short_ping'  => true,
        'avatar_size' => 48, // Kích thước avatar (px)
        'callback'    => 'ten_custom_comment_card', // (Tùy chọn) Hàm tự thiết kế layout bình luận
    ) );
    ?>
</ol>

3. Tùy biến từng thẻ bình luận (Custom Comment Card)

Khai báo hàm callback trong functions.php để làm chủ toàn bộ mã HTML từng dòng bình luận:

function ten_custom_comment_card( $comment, $args, $depth ) { ?>
    <li id="comment-<?php comment_ID(); ?>" <?php comment_class( 'comment-item' ); ?>>
        <article class="comment-body">
            
            <!-- 1. Ảnh đại diện Avatar (lấy theo Gravatar hoặc tài khoản) -->
            <div class="comment-avatar">
                <?php echo get_avatar( $comment, $args['avatar_size'], '', 'Avatar', array( 'class' => 'avatar-img' ) ); ?>
            </div>

            <div class="comment-content-wrap">
                <!-- 2. Tên người bình luận -->
                <h4 class="comment-author">
                    <?php echo get_comment_author_link( $comment ); ?>
                </h4>

                <!-- 3. Ngày và Giờ bình luận -->
                <div class="comment-meta text-muted">
                    <time datetime="<?php comment_time( 'c' ); ?>">
                        📅 <?php echo get_comment_date( 'd/m/Y', $comment ); ?> lúc <?php echo get_comment_time( 'H:i', $comment ); ?>
                    </time>
                </div>

                <!-- Trạng thái chờ duyệt (khi bình luận mới gửi) -->
                <?php if ( '0' == $comment->comment_approved ) : ?>
                    <p class="comment-awaiting text-warning"><em>Bình luận của bạn đang chờ quản trị viên duyệt.</em></p>
                <?php endif; ?>

                <!-- 4. Nội dung văn bản bình luận -->
                <div class="comment-text">
                    <?php comment_text(); ?>
                </div>

                <!-- 5. Nút Trả lời (Reply) -->
                <div class="comment-reply">
                    <?php
                    comment_reply_link( array_merge( $args, array(
                        'depth'     => $depth,
                        'max_depth' => $args['max_depth'],
                        'reply_text'=> '↩ Trả lời',
                    ) ) );
                    ?>
                </div>
            </div>

        </article>
<?php }

4. Nạp khung Form gửi bình luận (Comment Form)

Hàm comment_form() tự động tạo form gồm: ô nhập Họ tên, Email, Website, Nội dung và nút Gửi:

<!-- Đặt ở cuối file comments.php -->
<?php
comment_form( array(
    'title_reply'        => 'Để lại bình luận của bạn',
    'title_reply_to'     => 'Trả lời bình luận của %s',
    'cancel_reply_link'  => 'Hủy trả lời',
    'label_submit'       => 'Gửi bình luận',
    'class_submit'       => 'btn btn-primary submit-btn',
    'comment_field'      => '<p class="comment-form-comment"><textarea id="comment" name="comment" cols="45" rows="5" placeholder="Nội dung bình luận..." required></textarea></p>',
) );
?>
