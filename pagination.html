Hướng dẫn Custom UI Pagination (Phân trang) trong WordPress

Cách tùy biến giao diện phân trang chuẩn WordPress: bóc tách component trong template-parts/ui/, cấu hình tham số và hỗ trợ mượt mà cho cả Main Query lẫn WP_Query độc lập.

I. Cấu trúc HTML mặc định do WordPress sinh ra

Khi bạn gọi hàm the_posts_pagination(), WordPress sẽ tự động xuất ra khối HTML chuẩn với cấu trúc sau:

<nav class="navigation pagination" aria-label="Bài viết">
    <h2 class="screen-reader-text">Điều hướng bài viết</h2>
    <div class="nav-links">
        <a class="prev page-numbers" href="/page/1/">« Trước</a>
        <a class="page-numbers" href="/page/1/">1</a>
        <span aria-current="page" class="page-numbers current">2</span>
        <a class="page-numbers" href="/page/3/">3</a>
        <span class="page-numbers dots">…</span>
        <a class="page-numbers" href="/page/10/">10</a>
        <a class="next page-numbers" href="/page/3/">Sau »</a>
    </div>
</nav>

Bảng ý nghĩa các class CSS:

Class CSS Ý nghĩa & Vai trò
.navigation.pagination Thẻ <nav> bọc ngoài cùng của toàn bộ thanh phân trang.
.screen-reader-text Tiêu đề ẩn dành riêng cho thiết bị trợ thính (Accessibility).
.nav-links Khung chứa toàn bộ danh sách các nút bấm số trang.
.page-numbers Class chung cho tất cả các nút (cả số trang, nút Trước/Sau, dấu 3 chấm).
.page-numbers.current Trang HIỆN TẠI đang xem (dạng thẻ <span>, không bấm được).
.page-numbers.dots Dấu ba chấm (…) khi danh sách trang quá dài.
.prev / .next Nút chuyển về trang trước hoặc sang trang tiếp theo.

II. Bảng tham số tùy biến của the_posts_pagination()

Tham số (Key) Mặc định Mô tả chức năng
mid_size 2 Số lượng số trang hiển thị ở 2 bên trang hiện tại.
prev_text « Trước Chữ hoặc icon hiển thị cho nút trang trước (VD: &larr; Trước hoặc ‹).
next_text Sau » Chữ hoặc icon hiển thị cho nút trang sau (VD: Sau &rarr; hoặc ›).
screen_reader_text Posts navigation Đặt thành một khoảng trắng ' ' để ẩn chữ tiêu đề mặc định.
class pagination Class bổ sung thêm vào thẻ <nav> ngoài cùng.
total Tự động theo query Tổng số trang (dùng khi truyền số trang của custom WP_Query).

III. Đóng gói Component: template-parts/ui/pagination.php

Bóc tách phân trang thành một component độc lập để tái sử dụng ở mọi trang trong theme (Archive, Category, Taxonomy, Search, Custom Query...):

<?php
/**
 * Component: Phân trang (Pagination)
 * File: template-parts/ui/pagination.php
 */

// Thiết lập giá trị mặc định và hòa trộn tham số truyền vào
$args = wp_parse_args( $args, array(
    'total'     => null,
    'mid_size'  => 2,
    'prev_text' => '&larr; Trước',
    'next_text' => 'Sau &rarr;',
    'class'     => 'custom-pagination',
) );

$pagination_args = array(
    'mid_size'           => (int) $args['mid_size'],
    'prev_text'          => $args['prev_text'],
    'next_text'          => $args['next_text'],
    'screen_reader_text' => ' ', // Bỏ chữ điều hướng mặc định
    'class'              => $args['class'],
);

if ( ! empty( $args['total'] ) ) {
    $pagination_args['total'] = (int) $args['total'];
}

the_posts_pagination( $pagination_args );
?>

IV. Cách gọi component ra Template

1. Trong trang danh mục mặc định (Archive / Category / Taxonomy / Search)

Dùng với Main Query, WordPress tự biết tổng số trang và trang hiện tại, bạn không cần truyền tham số gì thêm:

<?php if ( have_posts() ) : ?>
    <div class="posts-grid">
        <?php while ( have_posts() ) : the_post(); ?>
            <?php get_template_part( 'template-parts/loop/card', get_post_type() ); ?>
        <?php endwhile; ?>
    </div>

    <!-- Gọi component phân trang -->
    <?php get_template_part( 'template-parts/ui/pagination' ); ?>
<?php endif; ?>

2. Trong câu truy vấn độc lập (Custom WP_Query)

Bắt buộc phải lấy biến $paged và truyền tổng số trang max_num_pages vào component:

<?php
$paged = get_query_var( 'paged' ) ? get_query_var( 'paged' ) : 1;

$custom_query = new WP_Query( array(
    'post_type'      => 'du-an',
    'posts_per_page' => 6,
    'paged'          => $paged,
) );

if ( $custom_query->have_posts() ) : ?>
    <div class="projects-grid">
        <?php while ( $custom_query->have_posts() ) : $custom_query->the_post(); ?>
            <?php get_template_part( 'template-parts/loop/card', 'du-an' ); ?>
        <?php endwhile; ?>
    </div>

    <!-- Truyền max_num_pages vào component pagination -->
    <?php 
    get_template_part( 'template-parts/ui/pagination', null, array(
        'total' => $custom_query->max_num_pages,
    ) ); 
    ?>

    <?php wp_reset_postdata(); // Luôn reset sau loop phụ! ?>
<?php endif; ?>

V. Code mẫu CSS hoàn chỉnh cho giao diện phân trang

Dưới đây là bộ CSS chuẩn đẹp, căn giữa, bo góc hiện đại và hỗ trợ hover/active tương thích cho cả Light & Dark mode:

VI. Lưu ý quan trọng tránh lỗi phân trang

⚠️ Lỗi bấm sang trang 2, 3 bị 404:
Thường xảy ra khi bạn dùng query_posts() hoặc tạo một WP_Query mới ghi đè lên template archive.
  • Giải pháp chuẩn mực: Luôn dùng hook pre_get_posts trong functions.php để điều chỉnh số bài mỗi trang (posts_per_page) thay vì can thiệp trực tiếp vào file template.
⚠️ Biến $paged ở Trang Chủ tĩnh (Static Front Page):
Nếu bạn cấu hình một Page làm Trang Chủ (trong Cài đặt → Đọc) và viết phân trang cho WP_Query tại đây, WordPress sử dụng query var page thay vì paged: 
$paged = get_query_var( 'page' ) ? get_query_var( 'page' ) : 1;
Nếu dùng get_query_var('paged') ở Trang Chủ tĩnh, biến sẽ luôn trả về 0 khiến bạn bấm sang trang 2 mà nội dung vẫn giữ nguyên trang 1!
