Gom file vào folder

Mặc định WordPress chỉ quét file ở thư mục gốc theme. Sử dụng bộ nạp template để gom file vào các folder con gọn gàng.

Thêm file inc/template-loader.php để WordPress tìm trong page/, single/, archive/ trước, rồi mới tới thư mục gốc:

<?php
$template_folders = array(
    'frontpage' => 'page',    'home'     => 'page',
    'page'      => 'page',    'single'   => 'single',
    'singular'  => 'single',  'attachment' => 'single',
    'archive'   => 'archive', 'category' => 'archive',
    'tag'       => 'archive', 'taxonomy' => 'archive',
    'author'    => 'archive', 'date'     => 'archive',
);

foreach ( $template_folders as $type => $folder ) {
    add_filter( "{$type}_template_hierarchy", function ( $templates ) use ( $folder ) {
        $result = array();
        foreach ( $templates as $template ) {
            if ( false === strpos( $template, '/' ) ) {
                $result[] = $folder . '/' . $template;
            }
            $result[] = $template;
        }
        return $result;
    } );
}

Nạp file này trong functions.php:

require_once get_stylesheet_directory() . '/inc/template-loader.php';
Page Template có khai báo Template Name: đặt trong thư mục templates/. WordPress đã tự động hỗ trợ quét một cấp thư mục con cho loại này mà không cần hook thêm.
