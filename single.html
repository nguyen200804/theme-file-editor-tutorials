Tạo Template Single Post-type (Trang chi tiết)

Template Single dùng để hiển thị chi tiết một bài viết duy nhất thuộc bài viết mặc định (post) hoặc một Custom Post Type bất kỳ (Sản phẩm, Dự án, Dịch vụ, Tuyển dụng...).

1. Quy tắc đặt tên file Template Single

Loại nội dung Tên file (hoặc đặt trong single/) Mức ưu tiên
Bài viết đơn theo slug single-{post_type}-{slug}.php
Ví dụ: single-post-gioi-thieu.php		 Cao nhất, áp dụng riêng cho 1 bài có slug chỉ định.
Custom Post Type single-{post_type}.php
Ví dụ: single-san-pham.php, single-du-an.php		 Áp dụng cho tất cả bài viết thuộc post type tương ứng.
Bài viết mặc định single-post.php Chuyên dụng cho post type post (Tin tức / Blog).
Dự phòng chung single.php → singular.php → index.php Nếu không có file cụ thể, WordPress sẽ dùng file dự phòng này.

2. Cấu trúc chuẩn file single-{post_type}.php

Code mẫu file single-san-pham.php (hoặc single/single-san-pham.php nếu dùng loader):

<?php
/**
 * Template chi tiết Sản phẩm (Custom Post Type: san-pham)
 */

get_header(); ?>

<main id="primary" class="site-main single-san-pham-wrap container">

    <?php
    while ( have_posts() ) :
        the_post(); ?>

        <!-- 1. Breadcrumb điều hướng -->
        <nav class="breadcrumb" aria-label="Đường dẫn trang">
            <a href="<?php echo esc_url( home_url( '/' ) ); ?>">Trang chủ</a> &raquo;
            <a href="<?php echo esc_url( get_post_type_archive_link( 'san-pham' ) ); ?>">Sản phẩm</a> &raquo;
            <span><?php the_title(); ?></span>
        </nav>

        <article id="post-<?php the_ID(); ?>" <?php post_class( 'single-product-detail' ); ?>>
            <div class="product-top-grid">
                <!-- Cột 1: Ảnh đại diện & Gallery -->
                <div class="product-gallery">
                    <?php if ( has_post_thumbnail() ) : ?>
                        <div class="main-image">
                            <?php the_post_thumbnail( 'large' ); ?>
                        </div>
                    <?php endif; ?>
                    <?php echo ten_gallery( 'album_anh' ); ?>
                </div>

                <!-- Cột 2: Thông tin sản phẩm & Đặt hàng -->
                <div class="product-summary">
                    <h1 class="product-title"><?php the_title(); ?></h1>

                    <div class="product-price">
                        <?php if ( ten_field( 'gia' ) ) : ?>
                            <span class="price"><?php echo esc_html( number_format_i18n( ten_field( 'gia' ) ) ); ?> đ</span>
                        <?php else : ?>
                            <span class="contact-price">Liên hệ để có giá tốt nhất</span>
                        <?php endif; ?>
                    </div>

                    <div class="product-short-desc">
                        <?php the_excerpt(); ?>
                    </div>

                    <a href="#dat-hang" class="btn btn-primary">Liên hệ đặt mua</a>
                </div>
            </div>

            <!-- 2. Nội dung mô tả chi tiết -->
            <section class="product-full-content">
                <h2>Mô tả chi tiết sản phẩm</h2>
                <div class="entry-content">
                    <?php the_content(); ?>
                </div>
            </section>
        </article>

        <!-- 3. Khối sản phẩm / bài viết liên quan (Related Items) -->
        <section class="related-posts">
            <h2>Sản phẩm liên quan</h2>
            <div class="product-grid">
                <?php
                $terms = get_the_terms( get_the_ID(), 'loai-san-pham' );
                $term_ids = ! empty( $terms ) && ! is_wp_error( $terms ) ? wp_list_pluck( $terms, 'term_id' ) : array();

                $related_args = array(
                    'post_type'      => 'san-pham',
                    'posts_per_page' => 4,
                    'post__not_in'   => array( get_the_ID() ), // Loại trừ sản phẩm đang xem
                    'orderby'        => 'rand',               // Lấy ngẫu nhiên
                );

                if ( ! empty( $term_ids ) ) {
                    $related_args['tax_query'] = array(
                        array(
                            'taxonomy' => 'loai-san-pham',
                            'field'    => 'term_id',
                            'terms'    => $term_ids,
                        ),
                    );
                }

                $related_query = new WP_Query( $related_args );

                if ( $related_query->have_posts() ) :
                    while ( $related_query->have_posts() ) : $related_query->the_post();
                        get_template_part( 'template-parts/loop/card', 'san-pham' );
                    endwhile;
                    wp_reset_postdata(); // Luôn reset postdata sau custom query
                endif;
                ?>
            </div>
        </section>

    <?php
    endwhile; // Kết thúc The Loop
    ?>

</main>

<?php get_footer(); ?>

3. Bóc tách thân bài bằng template-parts/content/

Nếu bạn muốn file single.php hoặc single-post.php dùng chung cấu trúc khung và chỉ khác biệt phần hiển thị nội dung, hãy bóc tách ra các file nhỏ trong thư mục template-parts/content/:

// Trong single.php
while ( have_posts() ) : the_post();
    get_template_part( 'template-parts/content/content', get_post_type() );
endwhile;

WordPress sẽ tự động tìm nạp:

  • template-parts/content/content-san-pham.php (nếu đang xem bài post type san-pham)
  • template-parts/content/content-post.php (nếu xem bài viết thường)
  • template-parts/content/content.php (dự phòng)

4. Các hàm tiện ích thường dùng trong trang Single

Hàm WordPress Ý nghĩa & Cách sử dụng
the_title() In ra tiêu đề bài viết.
the_content() In ra toàn bộ nội dung trong trình soạn thảo.
the_post_thumbnail('size') In thẻ <img> ảnh đại diện theo kích thước chỉ định (thumbnail, medium, large, full).
get_post_type_archive_link('pt') Lấy đường dẫn URL tới trang danh sách (Archive) của post type đó.
previous_post_link()
next_post_link()		 Tạo liên kết chuyển tiếp tới bài trước đó hoặc bài kế tiếp.
comments_template() Nạp khung bình luận và đánh giá của WordPress.
